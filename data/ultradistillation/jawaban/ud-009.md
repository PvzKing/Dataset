Pendekatannya: ubah setiap porsi menjadi pecahan eksak, hitung bagian proporsional tiap orang, ambil bagian bulatnya dengan pembulatan ke bawah, lalu bagikan sisa rupiah satu per satu berdasarkan pecahan desimal terbesar. Jika pecahan sama, urutan nama menentukan penerima sisa.

```python
from fractions import Fraction

def pecah_tagihan(total: int, porsi: dict[str, float]) -> dict[str, int]:
    if total < 0:
        raise ValueError("total tidak boleh negatif")
    if not porsi:
        raise ValueError("porsi tidak boleh kosong")

    porsi_fraksi = {}
    for nama, nilai in porsi.items():
        if nilai <= 0:
            raise ValueError("setiap porsi harus lebih dari 0")
        if isinstance(nilai, float):
            porsi_fraksi[nama] = Fraction(str(nilai))
        else:
            porsi_fraksi[nama] = Fraction(nilai)

    total_porsi = sum(porsi_fraksi.values(), Fraction(0, 1))
    hasil = {}
    fraksi = {}

    for nama, nilai in porsi_fraksi.items():
        bagian = Fraction(total, 1) * nilai / total_porsi
        dasar = bagian.numerator // bagian.denominator
        hasil[nama] = dasar
        fraksi[nama] = bagian - dasar

    sisa = total - sum(hasil.values())
    urutan = sorted(hasil.keys(), key=lambda nama: (-fraksi[nama], nama))

    for nama in urutan[:sisa]:
        hasil[nama] += 1

    return hasil
```

Contoh pemakaian: `pecah_tagihan(100, {"Budi": 2, "Ani": 1})` menghasilkan `{"Budi": 67, "Ani": 33}`. Kasus khusus yang ditangani: `total=0` menghasilkan semua nilai `0`; pecahan seri dibagikan menurut urutan nama; `total` negatif, `porsi` kosong, atau ada porsi `≤ 0` akan melempar `ValueError`.
