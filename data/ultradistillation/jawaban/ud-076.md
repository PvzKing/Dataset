Pendekatannya memakai algoritma divide and conquer klasik dengan kompleksitas O(n log n).
Pertama, titik diurutkan menurut koordinat x. Rentang titik lalu dibagi dua di tengah, dan jarak terkecil d di kedua belahan dicari secara rekursif. Setelah itu tinggal diperiksa pasangan yang melintasi garis pembagi. Pasangan seperti itu hanya mungkin berasal dari "jalur" titik yang berjarak horizontal kurang dari d dari garis tengah. Di dalam jalur yang terurut menurut y, setiap titik cukup dibandingkan dengan beberapa titik berikutnya, karena perulangan berhenti begitu selisih y mencapai d. Menurut argumen pengepakan, jumlah pembandingan ini terbatas oleh konstanta kecil.
Urutan menurut y dibangun sambil naik dari rekursi dengan cara menyambung dua list yang sudah terurut lalu memanggil `sort`. Timsort mendeteksi dua run tersebut dan menggabungkannya dalam waktu linear.
Kedalaman rekursi hanya sekitar log₂ n (±17 untuk 100.000 titik), jadi batas rekursi Python aman. Kasus semua titik pada satu garis vertikal tetap O(n log n), karena di setiap tingkat setiap titik jalur hanya berhadapan dengan satu atau dua tetangga. Titik kembar dideteksi lebih dulu dengan `set`, sehingga fungsi langsung mengembalikan `0.0`.

```python
import math
from operator import itemgetter


def pasangan_terdekat(titik: list[tuple[float, float]]) -> float:
    """Mengembalikan jarak Euclid terkecil di antara dua titik berindeks berbeda.

    Memakai divide and conquer O(n log n). Hasil selalu bertipe float.
    Kurang dari dua titik -> ValueError.
    """
    n = len(titik)
    if n < 2:
        raise ValueError("dibutuhkan paling sedikit dua titik")

    pts = []
    for t in titik:
        try:
            x, y = t
        except (TypeError, ValueError):
            raise ValueError(f"titik harus berupa pasangan (x, y): {t!r}")
        for v in (x, y):
            if isinstance(v, bool) or not isinstance(v, (int, float)):
                raise TypeError(f"koordinat harus int atau float: {v!r}")
            if isinstance(v, float) and not math.isfinite(v):
                raise ValueError(f"koordinat harus berhingga: {v!r}")
        pts.append((x, y))

    # Titik kembar (termasuk 1 dan 1.0, atau 0.0 dan -0.0) -> jarak 0
    if len(set(pts)) < n:
        return 0.0

    pts.sort()                      # urut menurut x, lalu y
    hypot = math.hypot
    kunci_y = itemgetter(1)
    tak_hingga = math.inf

    def rekursi(lo: int, hi: int):
        """Mengembalikan (jarak terkecil di pts[lo:hi], titik-titiknya terurut menurut y)."""
        if hi - lo <= 3:
            bag = pts[lo:hi]
            d = tak_hingga
            for i in range(len(bag)):
                xi, yi = bag[i]
                for j in range(i + 1, len(bag)):
                    xj, yj = bag[j]
                    dd = hypot(xj - xi, yj - yi)
                    if dd < d:
                        d = dd
            bag.sort(key=kunci_y)
            return d, bag

        mid = (lo + hi) // 2
        midx = pts[mid][0]
        dl, kiri = rekursi(lo, mid)
        dr, kanan = rekursi(mid, hi)
        d = dl if dl < dr else dr

        gabung = kiri + kanan
        gabung.sort(key=kunci_y)    # dua run terurut -> digabung secara linear

        jalur = [p for p in gabung if abs(p[0] - midx) < d]
        m = len(jalur)
        for i in range(m):
            xi, yi = jalur[i]
            for j in range(i + 1, m):
                xj, yj = jalur[j]
                dy = yj - yi
                if dy >= d:
                    break
                dx = abs(xj - xi)
                if dx >= d:
                    continue
                dd = hypot(dx, dy)
                if dd < d:
                    d = dd
        return d, gabung

    d, _ = rekursi(0, n)
    return float(d)

```

Contoh pemakaian:

```python
pasangan_terdekat([(0, 0), (3, 4), (1, 1)])        # 1.4142135623730951
pasangan_terdekat([(2, 5), (7, 1), (2, 5)])        # 0.0 (titik kembar)
pasangan_terdekat([(0, 0), (3, 4)])                # 5.0 (bertipe float)
pasangan_terdekat([(1.5, -2), (1, 3)])             # 5.024937810560445
pasangan_terdekat([(0, 0)])                        # ValueError

# Kasus berat: 100.000 titik pada satu garis vertikal
pasangan_terdekat([(0, 3 * i) for i in range(100_000)])   # 3.0

# 100.000 titik acak
import random
pts = [(random.uniform(-1e6, 1e6), random.uniform(-1e6, 1e6))
       for _ in range(100_000)]
pasangan_terdekat(pts)                             # selesai dalam hitungan detik

```

Kasus khusus yang ditangani:

* Kurang dari dua titik memicu `ValueError`.
* Titik kembar langsung menghasilkan `0.0` lewat pemeriksaan `set`. Pemeriksaan ini juga mengenali `(1, 2)` dan `(1.0, 2.0)` sebagai titik yang sama, begitu pula `0.0` dan `-0.0`.
* Semua titik pada satu garis vertikal (semua x sama) tetap O(n log n). Pembagian dilakukan menurut indeks, bukan nilai x, jadi kedua belahan selalu seimbang. Pemeriksaan jalur di tiap tingkat pun hanya menyentuh beberapa tetangga per titik.
* Garis horizontal, titik kolinear miring, dan sebaran acak tertangani dengan kompleksitas yang sama.
* Campuran int dan float didukung. Selisih koordinat int dihitung eksak sebelum `math.hypot`, yang juga menghindari overflow saat mengkuadratkan koordinat float yang besar. Hasil akhirnya selalu dikonversi ke `float`, termasuk ketika semua koordinat berupa int.
* Input tidak sah ditolak dengan pesan yang jelas. Titik yang bukan pasangan dua elemen dan koordinat NaN atau tak hingga memicu `ValueError`. Koordinat yang bukan bilangan, termasuk `bool`, memicu `TypeError`.
