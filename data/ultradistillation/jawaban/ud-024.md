Pendekatannya memakai metode lingkaran (circle method): satu tim dijadikan patokan, sisanya diputar setiap putaran. Jika jumlah tim ganjil, tambahkan satu slot dummy yang tidak dicantumkan dalam pasangan, sehingga setiap putaran tepat satu tim libur. Sebelum itu, jumlah tim kurang dari 2 langsung menghasilkan `[]`, dan nama kembar memicu `ValueError`.

```python
def jadwal_round_robin(tim: list[str]) -> list[list[tuple[str, str]]]:
    if len(tim) < 2:
        return []
    if len(set(tim)) != len(tim):
        raise ValueError("Nama tim tidak boleh kembar")

    daftar = list(tim)
    if len(daftar) % 2 == 1:
        daftar.append(None)

    jumlah = len(daftar)
    hasil: list[list[tuple[str, str]]] = []

    for _ in range(jumlah - 1):
        putaran: list[tuple[str, str]] = []
        for i in range(jumlah // 2):
            a = daftar[i]
            b = daftar[jumlah - 1 - i]
            if a is not None and b is not None:
                putaran.append((a, b))
        hasil.append(putaran)
        daftar = [daftar[0]] + [daftar[-1]] + daftar[1:-1]

    return hasil
```

Contoh pemakaian: `jadwal_round_robin(["A", "B", "C", "D"])` menghasilkan 3 putaran, dan setiap tim bermain tepat sekali per putaran. Untuk `["A", "B", "C"]` dihasilkan 3 putaran dengan satu tim libur di tiap putaran; pasangan dummy tidak dimasukkan. Kasus khusus yang ditangani: kurang dari 2 tim menghasilkan `[]`, sedangkan nama tim kembar seperti `["A", "A"]` melempar `ValueError`.
