Solusinya memakai algoritma Dinic, yang berjalan dalam fase-fase.

1. Pembentukan level. Setiap fase dimulai dengan BFS dari `s` pada graf residu untuk memberi level ke setiap simpul.
2. Augmentasi. Aliran didorong hanya lewat sisi yang naik tepat satu level, sampai tidak ada lagi jalur augmentasi pada graf berlevel itu. DFS ditulis iteratif agar tidak terkena batas rekursi Python. Setiap simpul punya penunjuk sisi (`it`) sehingga sisi yang sudah buntu tidak diperiksa ulang. Simpul buntu dipangkas dari level.
3. Penggabungan sisi. Sisi ganda dan sisi berlawanan arah digabung ke satu pasangan sisi maju–balik. Graf residu jadi lebih kecil dan perilakunya tetap benar.
4. Potongan minimum. BFS terakhir adalah BFS yang gagal mencapai `t`. Simpul yang terjangkau pada BFS itu persis himpunan sisi-s dari potongan minimum.

Untuk 2.000 simpul dan 20.000 sisi, cara ini selesai dalam waktu singkat.

```python
from collections import deque


def aliran_maksimum(n: int, sisi: list[tuple[int, int, int]], s: int, t: int) -> tuple[int, set[int]]:
    """Menghitung aliran maksimum s→t (algoritma Dinic) dan himpunan sisi-s potongan minimum."""
    if not (0 <= s < n) or not (0 <= t < n):
        raise ValueError("s atau t di luar rentang simpul")
    if s == t:
        raise ValueError("s dan t tidak boleh sama")

    adj = [[] for _ in range(n)]  # daftar indeks sisi residu per simpul
    ke = []                       # simpul tujuan setiap sisi residu
    kap = []                      # kapasitas residu setiap sisi
    indeks = {}                   # (u, v) -> indeks sisi residu u→v

    for u, v, c in sisi:
        if not (0 <= u < n) or not (0 <= v < n):
            raise ValueError(f"ujung sisi ({u}, {v}) di luar rentang")
        if c < 0:
            raise ValueError(f"kapasitas negatif pada sisi ({u}, {v})")
        if u == v or c == 0:
            continue
        e = indeks.get((u, v))
        if e is None:
            # buat pasangan sisi: e (u→v) dan e^1 (v→u)
            e = len(ke)
            ke.append(v); kap.append(0); adj[u].append(e)
            ke.append(u); kap.append(0); adj[v].append(e + 1)
            indeks[(u, v)] = e
            indeks[(v, u)] = e + 1
        kap[e] += c

    total = 0
    while True:
        # BFS: bentuk graf berlevel pada graf residu
        level = [-1] * n
        level[s] = 0
        antrean = deque([s])
        while antrean:
            u = antrean.popleft()
            lu = level[u] + 1
            for e in adj[u]:
                if kap[e] > 0:
                    v = ke[e]
                    if level[v] < 0:
                        level[v] = lu
                        antrean.append(v)
        if level[t] < 0:
            # level >= 0 tepat menandai simpul yang terjangkau dari s
            return total, {v for v in range(n) if level[v] >= 0}

        it = [0] * n
        while True:
            # DFS iteratif mencari satu jalur augmentasi pada graf berlevel
            jalur = []
            u = s
            while u != t:
                daftar = adj[u]
                i = it[u]
                m = len(daftar)
                target = level[u] + 1
                while i < m:
                    e = daftar[i]
                    if kap[e] > 0 and level[ke[e]] == target:
                        break
                    i += 1
                it[u] = i
                if i < m:
                    e = daftar[i]
                    jalur.append(e)
                    u = ke[e]
                else:
                    if u == s:
                        break             # tidak ada jalur lagi pada fase ini
                    level[u] = -1         # pangkas simpul buntu
                    e = jalur.pop()
                    u = ke[e ^ 1]
                    it[u] += 1
            if u != t:
                break
            f = min(kap[e] for e in jalur)
            for e in jalur:
                kap[e] -= f
                kap[e ^ 1] += f
            total += f

```

Contoh pemakaian

```python
sisi = [(0, 1, 3), (0, 2, 2), (1, 2, 5), (1, 3, 2), (2, 3, 3)]
aliran_maksimum(4, sisi, 0, 3)            # (5, {0})

aliran_maksimum(3, [(0, 1, 4), (1, 2, 1)], 0, 2)   # (1, {0, 1})
aliran_maksimum(3, [(0, 1, 4)], 0, 2)              # (0, {0, 1})  t tak terjangkau

```

Kasus khusus yang ditangani

* Sisi ganda: sisi seperti `(0, 1, 2)` dan `(0, 1, 3)` dijumlahkan menjadi kapasitas 5 pada satu sisi residu.
* Sisi berlawanan arah: `(u, v)` dan `(v, u)` berbagi satu pasangan sisi. Kapasitas `v→u` langsung menjadi kapasitas awal sisi baliknya, jadi hasil residunya tetap benar.
* Self-loop dan kapasitas 0: keduanya dilewati. Ujung sisi dan kapasitasnya tetap divalidasi lebih dulu, jadi self-loop dengan simpul di luar rentang tetap memicu `ValueError`.
* `t` tidak terjangkau dari `s`: hasilnya aliran 0, dengan himpunan berisi semua simpul yang terjangkau dari `s`.
* Validasi: `ValueError` dilempar untuk `s == t`, `s` atau `t` di luar `[0, n)` (termasuk saat `n ≤ 0`), ujung sisi di luar rentang, dan kapasitas negatif.
* Graf besar dan jalur panjang: BFS dan DFS sama-sama iteratif, sehingga tidak ada `RecursionError` pada rantai sepanjang 2.000 simpul.
