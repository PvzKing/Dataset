Pendekatannya memakai perubahan langsung di tempat dengan log pembatalan (undo log) per transaksi. Semua operasi tulis langsung diterapkan ke satu kamus data utama. Kamus lain menyimpan jumlah kunci per nilai, sehingga `ambil` dan `hitung` cukup sekali lookup hash tanpa menelusuri lapisan transaksi. Setiap transaksi terbuka memiliki kamus log yang mencatat nilai asli sebuah kunci, yaitu nilainya tepat sebelum kunci itu pertama kali diubah di transaksi tersebut. Kunci yang tidak ada dicatat dengan penanda khusus `_TIDAK_ADA`. Perubahan berikutnya pada kunci yang sama tidak menambah entri log.
Dengan struktur ini:

* `batal()` cukup membaca log transaksi terdalam dan memasang kembali nilai aslinya. Biayanya O(k), dengan k = banyaknya kunci berbeda yang diubah di transaksi itu.
* `komit()` menggabungkan log terdalam ke log di luarnya dengan `setdefault`. Jika kunci sudah tercatat di log luar, nilai asli versi luar yang lebih lama dipertahankan. Biayanya juga O(k). Data tidak perlu disalin karena sudah berada di tempatnya. Pada transaksi terluar, log cukup dibuang, sehingga perubahan menjadi permanen.
* `mulai()` hanya menumpuk satu kamus kosong, O(1).
* `ambil()` dan `hitung()` O(1) rata-rata. Kedalaman transaksi tidak berpengaruh karena keduanya tidak pernah menyentuh tumpukan log.

Memori tambahan sebanding dengan total kunci yang diubah di transaksi yang masih terbuka, bukan dengan ukuran data × kedalaman. Karena itu, 100.000 kunci dengan 2.000 transaksi bersarang tetap ringan.

```python
_TIDAK_ADA = object()  # penanda "kunci belum ada", berbeda dari nilai apa pun


class PenyimpanTransaksional:
    """Penyimpan kunci–nilai di memori dengan transaksi bersarang.

    Struktur data:
      _data   : dict kunci -> nilai (keadaan terkini, sudah termasuk
                perubahan di transaksi yang masih terbuka)
      _jumlah : dict nilai -> banyaknya kunci yang bernilai itu
      _log    : list berisi dict per transaksi terbuka;
                tiap dict memetakan kunci -> nilai aslinya sebelum
                pertama kali diubah di transaksi itu (_TIDAK_ADA jika
                kunci sebelumnya tidak ada)
    """

    __slots__ = ("_data", "_jumlah", "_log")

    def __init__(self):
        self._data = {}
        self._jumlah = {}
        self._log = []

    # ---------- operasi internal ----------

    def _tambah_jumlah(self, nilai):
        self._jumlah[nilai] = self._jumlah.get(nilai, 0) + 1

    def _kurangi_jumlah(self, nilai):
        sisa = self._jumlah[nilai] - 1
        if sisa:
            self._jumlah[nilai] = sisa
        else:
            del self._jumlah[nilai]

    def _pasang(self, kunci, baru):
        """Ubah data dan penghitung tanpa mencatat log. O(1)."""
        lama = self._data.get(kunci, _TIDAK_ADA)
        if lama is baru:
            return
        if lama is not _TIDAK_ADA:
            self._kurangi_jumlah(lama)
        if baru is _TIDAK_ADA:
            del self._data[kunci]
        else:
            self._data[kunci] = baru
            self._tambah_jumlah(baru)

    def _tulis(self, kunci, baru):
        """Catat nilai asli di log transaksi terdalam (sekali saja), lalu ubah."""
        if self._log:
            log = self._log[-1]
            if kunci not in log:
                log[kunci] = self._data.get(kunci, _TIDAK_ADA)
        self._pasang(kunci, baru)

    # ---------- API publik ----------

    def atur(self, kunci, nilai):
        if nilai is None:
            raise ValueError("nilai tidak boleh None")
        hash(nilai)  # nilai harus hashable agar bisa dihitung; TypeError jika tidak
        self._tulis(kunci, nilai)

    def ambil(self, kunci):
        return self._data.get(kunci)

    def hapus(self, kunci):
        if kunci in self._data:
            self._tulis(kunci, _TIDAK_ADA)

    def hitung(self, nilai):
        if nilai is None:
            return 0
        return self._jumlah.get(nilai, 0)

    def mulai(self):
        self._log.append({})

    def batal(self):
        if not self._log:
            raise RuntimeError("tidak ada transaksi yang terbuka")
        log = self._log.pop()
        for kunci, asli in log.items():
            self._pasang(kunci, asli)

    def komit(self):
        if not self._log:
            raise RuntimeError("tidak ada transaksi yang terbuka")
        log = self._log.pop()
        if self._log:
            luar = self._log[-1]
            for kunci, asli in log.items():
                # nilai asli versi transaksi luar (lebih lama) dipertahankan
                luar.setdefault(kunci, asli)
        # jika ini transaksi terluar, log cukup dibuang: perubahan permanen

    @property
    def kedalaman(self):
        return len(self._log)

    def __len__(self):
        return len(self._data)


def buat_penyimpan():
    return PenyimpanTransaksional()

```

Contoh pemakaian:

```python
p = buat_penyimpan()
p.atur("a", 10)
p.atur("b", 10)
p.hitung(10)        # 2

p.mulai()
p.atur("a", 20)
p.mulai()
p.hapus("b")
p.hitung(10)        # 0
p.batal()           # "b" kembali bernilai 10
p.ambil("b")        # 10
p.komit()           # "a" = 20 permanen
p.ambil("a")        # 20
p.hitung(10), p.hitung(20)   # (1, 1)

```

Uji skala (berjalan dalam hitungan detik atau kurang):

```python
p = buat_penyimpan()
for i in range(100_000):
    p.atur(i, i % 7)
for d in range(2_000):
    p.mulai()
    p.atur(d, "x")
p.hitung("x")       # 2000, O(1)
for _ in range(1_000):
    p.batal()
for _ in range(1_000):
    p.komit()
p.hitung("x")       # 1000

```

Kasus khusus yang ditangani:

* `batal()` atau `komit()` tanpa transaksi terbuka memunculkan `RuntimeError`.
* `atur(k, None)` memunculkan `ValueError`. `hitung(None)` mengembalikan 0 karena tidak ada kunci yang bisa bernilai `None`.
* `hapus` pada kunci yang tidak ada tidak memunculkan error dan tidak menambah entri log.
* Kunci yang diubah berkali-kali dalam satu transaksi hanya dicatat sekali, dengan nilai aslinya, sehingga `batal` tetap O(k).
* Kunci yang dibuat lalu dihapus, atau dihapus lalu dibuat lagi, di dalam transaksi dipulihkan dengan benar berkat penanda `_TIDAK_ADA`.
* Saat komit ke transaksi luar, kunci yang juga diubah di transaksi luar tetap memakai nilai asli versi luar. Jadi `batal()` di luar memulihkan keadaan sebelum transaksi luar dimulai, bukan keadaan di tengah-tengahnya.
* Nilai harus hashable agar bisa dihitung. Nilai yang tidak hashable, misalnya list, memunculkan `TypeError` sebelum data diubah. Perhatikan juga bahwa nilai yang sama menurut aturan hash Python, seperti `1`, `1.0`, dan `True`, dihitung sebagai nilai yang sama oleh `hitung`.
