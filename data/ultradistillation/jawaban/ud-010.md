Pendekatannya: validasi setiap transaksi dengan regex ketat `YYYY-MM-DD` lalu cek tanggalnya memakai `datetime.strptime`, tolak nominal negatif, kelompokkan nominal per bulan dan kategori, kemudian susun hasil akhir dengan bulan terurut naik dan kategori terurut abjad.

```python
from datetime import datetime
import re

def rekap_bulanan(transaksi: list[dict]) -> dict[str, dict[str, int]]:
    pola_tanggal = re.compile(r"^[0-9]{4}-[0-9]{2}-[0-9]{2}$")
    sementara: dict[str, dict[str, int]] = {}

    for item in transaksi:
        tanggal = item["tanggal"]
        if not isinstance(tanggal, str) or pola_tanggal.fullmatch(tanggal) is None:
            raise ValueError("Tanggal harus berformat YYYY-MM-DD")

        try:
            datetime.strptime(tanggal, "%Y-%m-%d")
        except ValueError:
            raise ValueError("Tanggal tidak valid") from None

        nominal = item["nominal"]
        if nominal < 0:
            raise ValueError("Nominal tidak boleh negatif")

        bulan = tanggal[:7]
        kategori = item["kategori"]

        if bulan not in sementara:
            sementara[bulan] = {}

        sementara[bulan][kategori] = sementara[bulan].get(kategori, 0) + nominal

    hasil: dict[str, dict[str, int]] = {}
    for bulan in sorted(sementara):
        hasil[bulan] = {
            kategori: sementara[bulan][kategori]
            for kategori in sorted(sementara[bulan])
        }

    return hasil
```

Contoh pemakaian: `rekap_bulanan([{"tanggal": "2026-01-05", "kategori": "makan", "nominal": 20000}, {"tanggal": "2026-01-10", "kategori": "makan", "nominal": 15000}, {"tanggal": "2026-02-01", "kategori": "transport", "nominal": 10000}])` menghasilkan `{"2026-01": {"makan": 35000}, "2026-02": {"transport": 10000}}`. Kasus khusus yang ditangani: tanggal salah format atau tidak valid melempar `ValueError`, nominal negatif melempar `ValueError`, nominal nol tetap diterima, bulan diurutkan naik, dan kategori dalam tiap bulan diurutkan menurut abjad.
