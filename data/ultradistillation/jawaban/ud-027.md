Pendekatannya memodelkan setiap trayek sebagai simpul graf; dua trayek dianggap terhubung jika berbagi minimal satu halte. BFS dari semua trayek yang melewati `asal` akan menghasilkan jumlah angkot minimum, karena setiap langkah BFS berarti menaiki satu angkot lagi. Jika `asal == tujuan`, jawabannya `0`; jika tidak ada trayek yang melewati asal/tujuan atau trayeknya tidak terhubung, jawabannya `-1`.

```python
from collections import deque

def transit_minimum(rute: dict[str, list[str]], asal: str, tujuan: str) -> int:
    if asal == tujuan:
        return 0

    stop_to_routes: dict[str, list[str]] = {}
    for nama_rute, daftar_halte in rute.items():
        for halte in daftar_halte:
            stop_to_routes.setdefault(halte, []).append(nama_rute)

    awal_routes = stop_to_routes.get(asal, [])
    tujuan_routes = set(stop_to_routes.get(tujuan, []))

    if not awal_routes or not tujuan_routes:
        return -1

    queue = deque()
    jarak = {}

    for nama_rute in awal_routes:
        if nama_rute not in jarak:
            jarak[nama_rute] = 1
            queue.append(nama_rute)

    while queue:
        nama_rute = queue.popleft()

        if nama_rute in tujuan_routes:
            return jarak[nama_rute]

        for halte in rute[nama_rute]:
            for rute_lain in stop_to_routes.get(halte, []):
                if rute_lain not in jarak:
                    jarak[rute_lain] = jarak[nama_rute] + 1
                    queue.append(rute_lain)

    return -1
```

Contoh pemakaian: `transit_minimum({"M01": ["Terminal", "Pasar", "Kampus"], "M02": ["Kampus", "RSUD"]}, "Terminal", "RSUD")` menghasilkan `2`; untuk `"Pasar"` ke `"Kampus"` menghasilkan `1`. Kasus khusus yang ditangani: asal sama dengan tujuan menghasilkan `0`; halte yang tidak dilewati trayek mana pun atau trayek yang tidak saling terhubung menghasilkan `-1`.
