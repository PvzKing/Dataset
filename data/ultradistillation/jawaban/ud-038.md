- **Form data pemberi kuasa (nama, NIK, alamat)** → fieldset "Pemberi Kuasa" dengan `#pkNama`, `#pkNik`, `#pkAlamat`.
- **Satu atau beberapa penerima kuasa (nama advokat, nomor KTA, alamat kantor)** → wadah `#kuasaList`, fungsi `buatKartu()` dan tombol `#addKuasa`, dibaca lewat `ambilKuasa()`.
- **Pihak lawan, pengadilan negeri, pokok perkara** → `#pihakLawan`, `#pengadilan`, `#pokokPerkara` pada fieldset "Perkara".
- **Pilihan hak substitusi** → checkbox `#hakSubstitusi` dan variabel `klausulSub` di `render()`.
- **Pratinjau berubah langsung saat form diisi** → listener `input`/`change` pada `#formPanel` yang memanggil `render()`.
- **Tanggal format Indonesia** → fungsi `tanggalIndo()` dengan array `BULAN` dan `new Date(v + 'T00:00:00')`.
- **Tempat tanda tangan dan meterai** → blok `.ttd` dua kolom, `.ttd-space`, dan kotak `.meterai` bertuliskan "Meterai Rp10.000".
- **Tampilan cetak rapi di A4** → `@page{size:A4;margin:18mm}` dan aturan `@media print` yang menyembunyikan `.topbar` dan `.form-panel`.
- **Profil kantor tersimpan di localStorage** → `simpanProfil()` dan `muatProfil()` dengan kunci `skk_kantor_v1`.
- **Akses localStorage dibungkus try/catch** → seluruh `setItem`, `getItem`, dan `removeItem` berada di dalam blok `try { … } catch (e) { }`.
- **Responsif sampai 375 px** → `@media (max-width:900px)` dan `@media (max-width:480px)` yang mengubah grid jadi satu kolom, mengecilkan padding kertas, dan menyetel ulang kolom identitas.
- **Tanpa library, font, gambar, atau file eksternal** → seluruh CSS dan JavaScript inline, hanya memakai font sistem (`-apple-system`, `"Times New Roman"`, dan sejenisnya).

**Catatan teknis**
Semua teks yang diketik pengguna dilewatkan melalui `esc()` sebelum masuk ke `innerHTML`, sehingga karakter seperti `<`, `>`, dan `&` tidak merusak struktur pratinjau; nilai alamat tetap mempertahankan baris baru lewat `white-space: pre-line`. Kolom "alamat kantor" pada kartu penerima kuasa otomatis terisi dari profil kantor saat kartu dibuat, dan profil disimpan dengan penundaan 300 ms agar tidak menulis ke localStorage pada setiap ketukan tombol. Saat mencetak, hanya elemen `.paper` yang tampil; jika isi surat melebihi satu halaman, daftar kuasa dan blok tanda tangan diberi `page-break-inside: avoid` agar tidak terpotong di tengah. Sesuai SEMA Nomor 6 Tahun 1994, surat menyebut kedudukan kedua pihak (Penggugat dan Tergugat), pengadilan, dan pokok perkara; peninjauan kembali sengaja tidak dicantumkan karena tetap memerlukan surat kuasa khusus tersendiri.
