Pendekatannya memakai dua jalur dengan hasil yang sama, dipilih otomatis berdasarkan perkiraan biaya.
Jalur cepat (pengelompokan per panjang). Pola unik dikelompokkan menurut panjangnya. Untuk setiap panjang L, setiap potongan `teks[i:i+L]` dicari langsung di dict pola yang panjangnya L. Pemotongan string dan lookup dict berjalan di level C, jadi untuk kasus target (pola 8–12 karakter, paling banyak lima panjang berbeda) totalnya hanya sekitar 1,5 juta lookup.
Jalur umum (Aho–Corasick). Jika panjang pola sangat beragam sehingga jalur cepat menjadi mahal, fungsi membangun trie dengan failure link dan dictionary suffix link. Teks lalu dipindai sekali dalam waktu O(|teks| + Σ|pola| + jumlah kemunculan). Semua kemunculan yang tumpang tindih tetap ditemukan, karena setiap posisi akhir menelusuri seluruh rantai pola yang berakhir di sana.
Pada kedua jalur, teks dipindai dari kiri ke kanan. Karena itu indeks awal untuk setiap pola otomatis tersusun naik. Pola kembar dihapus dengan `dict.fromkeys`, sehingga urutan kunci mengikuti kemunculan pertama.

```python
def cari_banyak_pola(teks: str, pola: list[str]) -> dict[str, list[int]]:
    """Mencari semua kemunculan (termasuk tumpang tindih) setiap pola di teks.

    Kunci: pola unik sesuai urutan kemunculan pertama di `pola`.
    Nilai: list indeks awal kemunculan, terurut naik (kosong jika tidak ada).
    """
    if not isinstance(teks, str):
        raise TypeError("teks harus berupa str")
    unik = list(dict.fromkeys(pola))
    for p in unik:
        if not isinstance(p, str):
            raise TypeError(f"pola harus berupa str: {p!r}")
        if p == "":
            raise ValueError("pola tidak boleh string kosong")
    if not unik:
        return {}

    n = len(teks)
    hasil: list[list[int]] = [[] for _ in unik]

    # Kelompokkan pola menurut panjang: panjang -> {pola: id}
    per_panjang: dict[int, dict[str, int]] = {}
    for idx, p in enumerate(unik):
        per_panjang.setdefault(len(p), {})[p] = idx

    # Perkiraan biaya jalur cepat (jumlah potongan, dibobot panjang potongan)
    biaya = sum((n - L + 1) * (1 + L // 64) for L in per_panjang if L <= n)

    if biaya <= 4_000_000:
        # ---- Jalur cepat: geser jendela untuk tiap panjang yang berbeda ----
        for L, grup in per_panjang.items():
            if L > n:
                continue
            get = grup.get
            for i in range(n - L + 1):
                idx = get(teks[i:i + L])
                if idx is not None:
                    hasil[idx].append(i)
    else:
        # ---- Jalur umum: Aho–Corasick ----
        goto: list[dict[str, int]] = [{}]
        keluaran = [-1]          # id pola yang berakhir tepat di simpul ini
        for idx, p in enumerate(unik):
            u = 0
            for ch in p:
                v = goto[u].get(ch)
                if v is None:
                    v = len(goto)
                    goto.append({})
                    keluaran.append(-1)
                    goto[u][ch] = v
                u = v
            keluaran[u] = idx

        jumlah = len(goto)
        gagal = [0] * jumlah
        tautan = [-1] * jumlah   # simpul terminal terdekat pada rantai gagal
        antrean = list(goto[0].values())
        for v in antrean:        # anak akar: gagal ke akar
            gagal[v] = 0
        kepala = 0
        while kepala < len(antrean):
            u = antrean[kepala]
            kepala += 1
            for ch, v in goto[u].items():
                f = gagal[u]
                while f and ch not in goto[f]:
                    f = gagal[f]
                fv = goto[f].get(ch, 0)
                gagal[v] = fv
                tautan[v] = fv if keluaran[fv] != -1 else tautan[fv]
                antrean.append(v)

        panjang = [len(p) for p in unik]
        u = 0
        for i, ch in enumerate(teks):
            while u and ch not in goto[u]:
                u = gagal[u]
            u = goto[u].get(ch, 0)
            t = u if keluaran[u] != -1 else tautan[u]
            while t != -1:
                idx = keluaran[t]
                hasil[idx].append(i - panjang[idx] + 1)
                t = tautan[t]

    return {p: hasil[i] for i, p in enumerate(unik)}

```

Contoh pemakaian:

```python
cari_banyak_pola("abababa", ["aba", "bab", "aba", "c"])
# {'aba': [0, 2, 4], 'bab': [1, 3], 'c': []}

cari_banyak_pola("aaaa", ["aa", "a"])
# {'aa': [0, 1, 2], 'a': [0, 1, 2, 3]}

cari_banyak_pola("teks apa saja", [])     # {}
cari_banyak_pola("abc", ["a", ""])        # ValueError

# Uji ukuran target
import random
teks = "".join(random.choice("acgt") for _ in range(300_000))
pola = [teks[j:j + random.randint(8, 12)]
        for j in random.sample(range(299_000), 30_000)]
r = cari_banyak_pola(teks, pola)          # selesai dalam hitungan detik

```

Kasus khusus yang ditangani:

* Kemunculan tumpang tindih dan pola yang merupakan bagian dari pola lain (misalnya `"a"` di dalam `"aa"`) semuanya dilaporkan. Pada jalur cepat, setiap posisi diperiksa untuk setiap panjang. Pada Aho–Corasick, dictionary suffix link menelusuri semua pola yang berakhir di posisi yang sama.
* Pola kembar hanya menghasilkan satu kunci, dengan urutan kunci sesuai kemunculan pertamanya di `pola`.
* Pola yang tidak muncul atau lebih panjang dari teks tetap menjadi kunci dengan nilai `[]`.
* Teks kosong menghasilkan list kosong untuk setiap pola.
* List `pola` kosong menghasilkan `{}`.
* Pola berupa string kosong memicu `ValueError`. Pola atau teks yang bukan `str` memicu `TypeError`.
* Panjang pola yang sangat beragam (misalnya ribuan panjang berbeda) otomatis dialihkan ke Aho–Corasick. Dengan begitu, waktu jalan tidak meledak menjadi O(|teks| × banyaknya panjang berbeda).
* Karakter Unicode apa pun didukung, karena kedua jalur bekerja langsung pada karakter `str`, bukan byte.
