Pendekatannya: periksa tipe, panjang, dan karakter NIK agar hanya 16 digit angka 0–9; pecah menjadi kode wilayah, tanggal lahir, dan nomor urut; tolak kode wilayah yang memiliki segmen `00` serta nomor urut `0000`; tentukan jenis kelamin dari nilai DD (lebih dari 40 berarti perempuan dan DD dikurangi 40); susun tahun dari `tahun_acuan`; lalu validasi tanggal memakai `datetime.date`.

```python
from datetime import date

def info_nik(nik: str, tahun_acuan: int) -> dict | None:
    if not isinstance(nik, str) or len(nik) != 16:
        return None
    if any(c not in "0123456789" for c in nik):
        return None

    kode_wilayah = nik[:6]
    if any(kode_wilayah[i:i + 2] == "00" for i in (0, 2, 4)):
        return None

    nomor_urut = nik[12:16]
    if nomor_urut == "0000":
        return None

    dd_raw = int(nik[6:8])
    mm = int(nik[8:10])
    yy = int(nik[10:12])

    if dd_raw > 40:
        jenis_kelamin = "P"
        dd = dd_raw - 40
    else:
        jenis_kelamin = "L"
        dd = dd_raw

    tahun = 2000 + yy if 2000 + yy <= tahun_acuan else 1900 + yy

    try:
        tanggal_lahir = date(tahun, mm, dd)
    except ValueError:
        return None

    return {
        "kode_wilayah": kode_wilayah,
        "tanggal_lahir": tanggal_lahir,
        "jenis_kelamin": jenis_kelamin,
        "nomor_urut": nomor_urut,
    }
```

Contoh pemakaian: `info_nik("3171234505900001", 2026)` mengembalikan `{'kode_wilayah': '317123', 'tanggal_lahir': datetime.date(1990, 5, 5), 'jenis_kelamin': 'P', 'nomor_urut': '0001'}`. Kasus khusus yang ditangani: panjang bukan 16, karakter selain 0–9, salah satu segmen kode wilayah `00`, nomor urut `0000`, dan tanggal tidak valid seperti 31 Februari; semuanya mengembalikan `None`.
