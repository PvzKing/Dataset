Pendekatannya: hitung jumlah hari sebelum tahun dan sebelum bulan untuk menentukan hari pertama bulan tersebut dengan Senin sebagai indeks 0, tentukan panjang bulan dengan aturan kabisat, lalu isi tanggal dengan nol di awal/akhir agar setiap baris tepat 7 angka. Bulan divalidasi di awal dan `ValueError` dilempar jika tidak valid.

```python
def kalender_bulan(tahun: int, bulan: int) -> list[list[int]]:
    if bulan < 1 or bulan > 12:
        raise ValueError("bulan harus bernilai 1 sampai 12")

    def tahun_kabisat(y: int) -> bool:
        return y % 4 == 0 and (y % 100 != 0 or y % 400 == 0)

    panjang_bulan = [
        31,
        29 if tahun_kabisat(tahun) else 28,
        31,
        30,
        31,
        30,
        31,
        31,
        30,
        31,
        30,
        31,
    ]

    hari_sebelum_tahun = (
        365 * (tahun - 1)
        + (tahun - 1) // 4
        - (tahun - 1) // 100
        + (tahun - 1) // 400
    )
    hari_sebelum_bulan = sum(panjang_bulan[: bulan - 1])

    offset_awal = (hari_sebelum_tahun + hari_sebelum_bulan) % 7
    jumlah_hari = panjang_bulan[bulan - 1]

    sel = [0] * offset_awal + list(range(1, jumlah_hari + 1))
    while len(sel) % 7 != 0:
        sel.append(0)

    return [sel[i:i + 7] for i in range(0, len(sel), 7)]
```

Contoh pemakaian: `kalender_bulan(2026, 10)[0]` menghasilkan `[0, 0, 0, 1, 2, 3, 4]`. Kasus khusus yang ditangani: Februari tahun kabisat seperti `kalender_bulan(2024, 2)` memuat tanggal 29, dan bulan tidak valid seperti `kalender_bulan(2026, 13)` melempar `ValueError`.
