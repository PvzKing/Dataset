Pengujiannya berlapis. Lapisan pertama adalah kasus batas tetap dengan jawaban yang ditulis tangan: list kosong, rentang satu titik `(a, a)`, rentang bersebelahan dan berjarak satu, rentang yang memuat rentang lain, duplikat, rantai penggabungan, bilangan negatif, bilangan sangat besar, dan masukan yang tidak urut. Lapisan kedua adalah tes acak dengan oracle. Oracle-nya sengaja dibuat dengan cara yang sama sekali berbeda dari implementasi pada umumnya: semua bilangan bulat yang tercakup dimasukkan ke sebuah `set`, lalu dipecah menjadi deret berurutan yang maksimal. Generatornya memakai seed tetap supaya hasilnya deterministik, dan rentang nilainya sempit agar tumpang tindih dan persinggungan sering muncul.
Lapisan ketiga adalah tes properti pada setiap kasus acak. Hasil tidak boleh berubah jika urutan masukan diacak atau dibalik. Fungsi harus idempoten, artinya `f(f(x)) == f(x)`. Hasil harus ikut bergeser jika semua rentang digeser sejauh k; pergeseran sejauh 10¹² atau 2⁷⁰ menangkap implementasi yang diam-diam memakai larik berbatas atau float. Pemanggilan berulang dengan masukan yang sama harus memberi hasil sama, sehingga state tersembunyi seperti default argumen yang mutable ikut tertangkap.
Setiap hasil juga diperiksa bentuknya. Hasil harus berupa `list` berisi `tuple` dua `int` dengan a ≤ b, dan setiap rentang harus dimulai minimal dua angka setelah ujung rentang sebelumnya, yaitu urut dan tidak bersentuhan. Masukan dibandingkan dengan salinannya setelah setiap pemanggilan, termasuk saat `ValueError` dilempar. Untuk kasus galat, rentang dengan a > b disisipkan di posisi awal, tengah, atau akhir, dan juga di posisi yang tertutupi rentang lain, seperti `[(0, 10), (5, 4)]`. Dengan begitu implementasi yang hanya memvalidasi sebagian rentang ikut tertangkap. Exception apa pun selain yang semestinya diubah menjadi `AssertionError`.

```python
import random


def uji_gabung_rentang(fungsi):
    def gagal(pesan):
        raise AssertionError(pesan)

    def panggil(data):
        salinan = list(data)
        try:
            hasil = fungsi(data)
        except Exception as e:
            raise AssertionError(
                f"exception tak semestinya untuk {salinan!r}: {e!r}"
            ) from e
        if data != salinan:
            gagal(f"masukan diubah: {salinan!r} menjadi {data!r}")
        return hasil

    def periksa_bentuk(hasil, masukan):
        if not isinstance(hasil, list):
            gagal(f"hasil bukan list untuk {masukan!r}: {hasil!r}")
        for t in hasil:
            if not isinstance(t, tuple) or len(t) != 2:
                gagal(f"elemen hasil bukan tuple 2 unsur: {t!r} (masukan {masukan!r})")
            a, b = t
            if type(a) is not int or type(b) is not int:
                gagal(f"elemen hasil bukan int: {t!r} (masukan {masukan!r})")
            if a > b:
                gagal(f"rentang hasil tidak valid: {t!r} (masukan {masukan!r})")
        for (a1, b1), (a2, b2) in zip(hasil, hasil[1:]):
            if a2 <= b1 + 1:
                gagal(
                    f"hasil tidak urut atau belum tergabung: {(a1, b1)!r}, "
                    f"{(a2, b2)!r} (masukan {masukan!r})"
                )

    def cek(data, harapan):
        masukan = list(data)
        hasil = panggil(data)
        periksa_bentuk(hasil, masukan)
        if hasil != harapan:
            gagal(f"untuk {masukan!r} diharapkan {harapan!r}, didapat {hasil!r}")
        return hasil

    def harus_valueerror(data):
        salinan = list(data)
        try:
            hasil = fungsi(data)
        except ValueError:
            pass
        except Exception as e:
            raise AssertionError(
                f"harus ValueError untuk {salinan!r}, didapat {e!r}"
            ) from e
        else:
            gagal(f"harus ValueError untuk {salinan!r}, malah mengembalikan {hasil!r}")
        if data != salinan:
            gagal(f"masukan diubah saat galat: {salinan!r} menjadi {data!r}")

    def oracle(data):
        titik = set()
        for a, b in data:
            titik.update(range(a, b + 1))
        runs = []
        for x in sorted(titik):
            if runs and runs[-1][1] == x - 1:
                runs[-1][1] = x
            else:
                runs.append([x, x])
        return [tuple(r) for r in runs]

    # 1. Kasus batas tetap
    besar = 10**18
    kasus_tetap = [
        ([], []),
        ([(5, 5)], [(5, 5)]),
        ([(0, 0)], [(0, 0)]),
        ([(-7, -7)], [(-7, -7)]),
        ([(1, 3), (4, 6)], [(1, 6)]),
        ([(4, 6), (1, 3)], [(1, 6)]),
        ([(1, 3), (5, 6)], [(1, 3), (5, 6)]),
        ([(5, 6), (1, 3)], [(1, 3), (5, 6)]),
        ([(1, 3), (3, 5)], [(1, 5)]),
        ([(1, 10), (2, 3)], [(1, 10)]),
        ([(2, 3), (1, 10)], [(1, 10)]),
        ([(1, 10), (2, 3), (11, 12)], [(1, 12)]),
        ([(1, 10), (2, 3), (12, 12)], [(1, 10), (12, 12)]),
        ([(1, 5), (2, 3), (4, 4)], [(1, 5)]),
        ([(1, 2), (1, 2)], [(1, 2)]),
        ([(3, 3), (3, 3), (3, 3)], [(3, 3)]),
        ([(0, 0), (1, 1), (2, 2)], [(0, 2)]),
        ([(2, 2), (0, 0), (1, 1)], [(0, 2)]),
        ([(0, 0), (2, 2)], [(0, 0), (2, 2)]),
        ([(1, 4), (0, 0)], [(0, 4)]),
        ([(0, 0), (-1, -1)], [(-1, 0)]),
        ([(-5, -3), (-2, 0)], [(-5, 0)]),
        ([(-5, -3), (-1, 0)], [(-5, -3), (-1, 0)]),
        ([(-3, 3), (-10, -4), (4, 9)], [(-10, 9)]),
        ([(10, 20), (1, 2), (5, 6), (3, 4)], [(1, 6), (10, 20)]),
        ([(1, 10), (2, 3), (5, 20)], [(1, 20)]),
        ([(5, 20), (1, 10), (2, 3)], [(1, 20)]),
        ([(1, 2), (3, 4), (6, 7), (8, 9)], [(1, 4), (6, 9)]),
        ([(-besar, besar), (0, 1)], [(-besar, besar)]),
        ([(besar, besar + 1), (besar + 2, besar + 3)], [(besar, besar + 3)]),
        ([(-besar, -besar), (besar, besar)], [(-besar, -besar), (besar, besar)]),
    ]
    for data, harapan in kasus_tetap:
        if max((abs(x) for r in data for x in r), default=0) < 1000 and oracle(data) != harapan:
            gagal(f"kasus tetap keliru: {data!r}")  # pengaman internal
        cek(list(data), harapan)

    # 2. Kasus galat tetap
    kasus_galat = [
        [(2, 1)],
        [(0, -1)],
        [(-1, -2)],
        [(5, 3), (0, 0)],
        [(0, 0), (5, 3)],
        [(1, 3), (10, 2), (4, 5)],
        [(0, 10), (5, 4)],
        [(5, 4), (0, 10)],
        [(1, 2), (3, 4), (8, 7)],
        [(1, 1), (1, 0)],
        [(besar, -besar)],
    ]
    for data in kasus_galat:
        harus_valueerror(list(data))

    # 3. Tes acak dengan oracle dan tes properti
    rng = random.Random(20261023)
    geseran = [1, -1, 37, -1000, 10**12, -(10**15), 2**70]

    def rentang_acak():
        a = rng.randint(-15, 15)
        return (a, a + rng.choice([0, 0, 0, 1, 1, 2, 3, 5, 8]))

    for _ in range(1500):
        data = [rentang_acak() for _ in range(rng.randint(0, 8))]
        harapan = oracle(data)

        cek(list(data), harapan)
        cek(list(data), harapan)  # pemanggilan ulang: tidak boleh ada state

        acak = list(data)
        rng.shuffle(acak)
        cek(acak, harapan)
        cek(list(reversed(data)), harapan)

        cek(list(harapan), harapan)  # idempoten

        k = rng.choice(geseran)
        cek([(a + k, b + k) for a, b in data],
            [(a + k, b + k) for a, b in harapan])

    # 4. Galat acak: rentang terbalik di posisi sembarang
    for _ in range(400):
        data = [rentang_acak() for _ in range(rng.randint(0, 6))]
        if data and rng.random() < 0.5:
            a0, b0 = rng.choice(data)  # sering tertutupi rentang lain
            a = rng.randint(a0, b0)
        else:
            a = rng.randint(-15, 15)
        buruk = (a, a - rng.randint(1, 5))
        data.insert(rng.randint(0, len(data)), buruk)
        harus_valueerror(data)

    return None
```

```python
def benar(rentang):
    for a, b in rentang:
        if a > b:
            raise ValueError("a > b")
    hasil = []
    for a, b in sorted(rentang):
        if hasil and a <= hasil[-1][1] + 1:
            hasil[-1] = (hasil[-1][0], max(hasil[-1][1], b))
        else:
            hasil.append((a, b))
    return hasil

def salah(rentang):              # bug: memakai b, bukan max(...)
```

Bug-bug halus yang tertangkap:

* Kesalahan batas penggabungan. Rentang bersebelahan tidak digabung (`<=` ditulis `<`), rentang berjarak dua ikut digabung, atau ujung baru tidak memakai `max` sehingga rentang yang memuat rentang lain terpotong.
* Kesalahan pengurutan. Masukan tidak diurutkan, diurutkan menurut ujung, atau awal rentang hasil diambil dari elemen yang salah.
* Pengubahan masukan. Contohnya `rentang.sort()`, termasuk jika pengubahan terjadi sebelum `ValueError` dilempar.
* Validasi yang tidak lengkap. Hanya elemen pertama yang diperiksa, rentang terbalik yang tertutupi rentang lain lolos, `(a, a)` ditolak karena memakai `a >= b`, atau exception yang dilempar bukan `ValueError`.
* Tipe hasil yang salah. Hasil berupa list of lists, tuple, atau generator, atau nilainya dikonversi ke float.
* Kesalahan pada masukan khusus. Gagal atau crash pada list kosong, atau bermasalah pada bilangan negatif dan bilangan sangat besar.
* State tersembunyi antar-pemanggilan.

Implementasi benar yang ditulis dengan cara lain tetap lolos. Contohnya implementasi yang mengurutkan berdasarkan tuple atau hanya berdasarkan awal rentang, melakukan validasi sebelum atau sesudah pengurutan, atau mengembalikan list baru dengan tuple yang sama objeknya. Pengujian hanya menuntut hal yang ditetapkan spesifikasi; `ValueError` turunan pun diterima.
