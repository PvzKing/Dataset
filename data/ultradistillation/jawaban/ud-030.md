Pendekatannya: urutkan nama pemain, lalu telusuri semua subset yang mungkin untuk tim pertama dengan syarat tim pertama memuat nama pertama menurut abjad dan selisih ukuran kedua tim maksimal satu. Untuk setiap kandidat, hitung selisih total skor; pilih yang paling kecil. Jika ada seri, dipilih tim pertama yang urutan namanya paling kecil secara leksikografis agar hasil deterministik. Tim kedua adalah sisanya, dan karena nama sudah terurut, kedua tim otomatis terurut abjad.

```python
from itertools import combinations

def bagi_tim_seimbang(pemain: dict[str, int]) -> tuple[list[str], list[str]]:
    if len(pemain) < 2:
        raise ValueError("Jumlah pemain minimal 2")

    nama = sorted(pemain)
    n = len(nama)
    total = sum(pemain[x] for x in nama)
    pertama = nama[0]
    sisa = nama[1:]

    ukuran_kandidat = []
    for s1 in (n // 2, (n + 1) // 2):
        if abs(s1 - (n - s1)) <= 1 and s1 not in ukuran_kandidat:
            ukuran_kandidat.append(s1)

    best_tim1 = None
    best_key = None

    for s1 in ukuran_kandidat:
        k = s1 - 1
        if k < 0 or k > len(sisa):
            continue

        for combo in combinations(sisa, k):
            tim1 = [pertama] + list(combo)
            skor1 = pemain[pertama] + sum(pemain[x] for x in combo)
            selisih = abs(2 * skor1 - total)
            key = (selisih, tim1)

            if best_key is None or key < best_key:
                best_key = key
                best_tim1 = tim1

    himpunan_tim1 = set(best_tim1)
    tim2 = [x for x in nama if x not in himpunan_tim1]

    return (best_tim1, tim2)
```

Contoh pemakaian: `bagi_tim_seimbang({"Ana": 7, "Budi": 5, "Citra": 4})` menghasilkan `(["Ana"], ["Budi", "Citra"])`.

Kasus khusus yang ditangani: jumlah pemain kurang dari 2 melempar `ValueError`; jumlah pemain genap maupun ganjil tetap memenuhi selisih anggota maksimal satu; skor negatif atau seri tetap dihitung dengan benar; dan jika ada beberapa pembagian dengan selisih skor sama, hasil dipilih secara deterministik.
