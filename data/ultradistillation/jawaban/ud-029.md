Pendekatannya: tentukan nilai minimum dan maksimum, hitung lebar kelas dengan pembagian ceiling, lalu bentuk tepat `k` kelas berurutan dan hitung frekuensi tiap kelas secara inklusif. Validasi dilakukan di awal untuk `data` kosong dan `k < 1`.

```python
def distribusi_frekuensi(data: list[int], k: int) -> list[tuple[int, int, int]]:
    if not data:
        raise ValueError("data tidak boleh kosong")
    if k < 1:
        raise ValueError("k harus lebih besar atau sama dengan 1")

    nilai_min = min(data)
    nilai_max = max(data)
    rentang = nilai_max - nilai_min + 1
    lebar_kelas = (rentang + k - 1) // k

    hasil = []
    for i in range(k):
        batas_bawah = nilai_min + i * lebar_kelas
        batas_atas = batas_bawah + lebar_kelas - 1
        frekuensi = sum(
            1 for nilai in data
            if batas_bawah <= nilai <= batas_atas
        )
        hasil.append((batas_bawah, batas_atas, frekuensi))

    return hasil
```

Contoh pemakaian: `distribusi_frekuensi([70, 75, 80, 85, 90], 3)` menghasilkan `[(70, 76, 2), (77, 83, 1), (84, 90, 2)]`.

Kasus khusus yang ditangani: `data` kosong dan `k < 1` memunculkan `ValueError`; nilai negatif tetap dihitung dengan benar; jika `k` lebih besar dari rentang nilai, tetap terbentuk tepat `k` kelas dan kelas kosong memiliki frekuensi `0`; nilai duplikat dihitung sesuai kemunculannya.
