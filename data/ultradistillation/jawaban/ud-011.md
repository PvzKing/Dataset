Pendekatannya: jumlahkan hasil kali setiap nilai dengan bobotnya, lalu bagi dengan total bobot, bukan dengan jumlah elemen. Kesalahan kode awal: perulangan mulai dari indeks 1 sehingga elemen pertama terlewat, pembagi memakai `len(bobot)` bukan jumlah bobot, dan tidak ada validasi panjang, daftar kosong, serta total bobot nol.

```python
def rata_rata_tertimbang(nilai, bobot):
    if len(nilai) != len(bobot):
        raise ValueError("Panjang nilai dan bobot harus sama")
    if len(nilai) == 0:
        raise ValueError("Daftar nilai dan bobot tidak boleh kosong")

    total_bobot = sum(bobot)
    if total_bobot == 0:
        raise ValueError("Total bobot tidak boleh nol")

    total = 0
    for n, b in zip(nilai, bobot):
        total += n * b

    return total / total_bobot
```

Contoh pemakaian: `rata_rata_tertimbang([80, 90], [1, 3])` menghasilkan `87.5`. Kasus khusus yang ditangani: panjang `nilai` dan `bobot` berbeda, daftar kosong, dan total bobot bernilai nol semuanya melempar `ValueError`.
