Pendekatannya terdiri dari dua tahap. Tahap pertama adalah validasi tanpa rekursi. Fungsi memeriksa `pekerja`, memastikan setiap dependensi merujuk ke tugas yang ada, lalu mendeteksi siklus dengan algoritma Kahn yang memakai antrean. Jika ada tugas yang tidak pernah mencapai derajat masuk nol, berarti ada siklus, termasuk tugas yang bergantung pada dirinya sendiri. Karena seluruhnya iteratif, rantai sepanjang ribuan tugas aman dari batas rekursi.
Tahap kedua adalah eksekusi dengan `ThreadPoolExecutor(max_workers=pekerja)`, sehingga paling banyak `pekerja` fungsi berjalan bersamaan. Setiap tugas punya penghitung dependensi yang belum selesai. Thread utama menunggu dengan `wait(..., FIRST_COMPLETED)`. Begitu satu tugas sukses, penghitung tugas-tugas yang bergantung padanya dikurangi, dan tugas yang penghitungnya menjadi nol langsung dikirim ke pool tanpa menunggu tingkat lain. Jika sebuah tugas gagal, exception-nya dicatat. Semua turunannya, langsung maupun tidak langsung, ditandai sebagai dilewati melalui penelusuran berbasis tumpukan eksplisit, sehingga tidak akan pernah dikirim. Tugas lain tetap berjalan seperti biasa.

```python
from __future__ import annotations

from collections import deque
from concurrent.futures import FIRST_COMPLETED, ThreadPoolExecutor, wait
from typing import Callable


def jalankan_dag(
    tugas: dict[str, tuple[Callable[[dict], object], list[str]]],
    pekerja: int,
) -> tuple[dict, dict, set]:
    # ---------- Validasi ----------
    if pekerja < 1:
        raise ValueError(f"pekerja harus >= 1, diberikan {pekerja!r}")

    deps: dict[str, list[str]] = {}
    for nama, entri in tugas.items():
        try:
            fungsi, dependensi = entri
        except (TypeError, ValueError):
            raise ValueError(f"entri tugas {nama!r} harus berbentuk (fungsi, dependensi)") from None
        if not callable(fungsi):
            raise ValueError(f"fungsi untuk tugas {nama!r} tidak dapat dipanggil")
        unik = list(dict.fromkeys(dependensi))  # buang duplikat, urutan tetap
        for d in unik:
            if d not in tugas:
                raise ValueError(f"tugas {nama!r} bergantung pada tugas tak dikenal {d!r}")
        deps[nama] = unik

    dependen: dict[str, list[str]] = {n: [] for n in tugas}
    sisa: dict[str, int] = {}
    for nama, ds in deps.items():
        sisa[nama] = len(ds)
        for d in ds:
            dependen[d].append(nama)

    # Deteksi siklus (Kahn, iteratif)
    derajat = dict(sisa)
    antrean = deque(n for n, c in derajat.items() if c == 0)
    terproses = 0
    while antrean:
        n = antrean.popleft()
        terproses += 1
        for m in dependen[n]:
            derajat[m] -= 1
            if derajat[m] == 0:
                antrean.append(m)
    if terproses != len(tugas):
        terlibat = [n for n, c in derajat.items() if c > 0]
        contoh = ", ".join(repr(n) for n in terlibat[:5])
        raise ValueError(f"terdapat siklus dependensi (melibatkan antara lain: {contoh})")

    # ---------- Eksekusi ----------
    hasil: dict[str, object] = {}
    gagal: dict[str, Exception] = {}
    dilewati: set[str] = set()

    if not tugas:
        return hasil, gagal, dilewati

    with ThreadPoolExecutor(max_workers=pekerja) as eksekutor:
        berjalan: dict = {}

        def kirim(nama: str) -> None:
            fungsi = tugas[nama][0]
            masukan = {d: hasil[d] for d in deps[nama]}
            berjalan[eksekutor.submit(fungsi, masukan)] = nama

        for nama in tugas:
            if sisa[nama] == 0:
                kirim(nama)

        while berjalan:
            selesai, _ = wait(berjalan, return_when=FIRST_COMPLETED)
            for fut in selesai:
                nama = berjalan.pop(fut)
                try:
                    nilai = fut.result()
                except Exception as exc:
                    gagal[nama] = exc
                    # Tandai semua turunan sebagai dilewati (tanpa rekursi)
                    tumpukan = list(dependen[nama])
                    while tumpukan:
                        m = tumpukan.pop()
                        if m in dilewati:
                            continue
                        dilewati.add(m)
                        tumpukan.extend(dependen[m])
                    continue

                hasil[nama] = nilai
                for m in dependen[nama]:
                    sisa[m] -= 1
                    if sisa[m] == 0 and m not in dilewati:
                        kirim(m)

    return hasil, gagal, dilewati

```

Contoh pemakaian:

```python
import time

def lambat(nilai, jeda=0.1):
    def f(inp):
        time.sleep(jeda)
        return nilai + sum(inp.values())
    return f

def rusak(_):
    raise RuntimeError("gagal")

tugas = {
    "a": (lambat(1), []),
    "b": (lambat(2), ["a"]),
    "c": (rusak, ["a"]),
    "d": (lambat(10), ["c"]),       # dilewati karena c gagal
    "e": (lambat(100), ["d", "b"]), # dilewati secara tidak langsung
    "f": (lambat(5), []),           # tidak berkaitan, tetap jalan
}
hasil, gagal, dilewati = jalankan_dag(tugas, pekerja=2)
# hasil    -> {'a': 1, 'f': 5, 'b': 3}   (urutan kunci bisa berbeda)
# gagal    -> {'c': RuntimeError('gagal')}
# dilewati -> {'d', 'e'}

# Rantai panjang tanpa masalah rekursi:
rantai = {"t0": (lambda inp: 0, [])}
for i in range(1, 5000):
    rantai[f"t{i}"] = (lambda inp: next(iter(inp.values())) + 1, [f"t{i-1}"])
hasil, _, _ = jalankan_dag(rantai, pekerja=4)
# hasil["t4999"] -> 4999

```

Kasus khusus yang ditangani:

* `pekerja < 1`: langsung `ValueError`, dan tidak ada fungsi yang dipanggil.
* Dependensi ke nama yang tidak ada: `ValueError` sebelum eksekusi.
* Siklus: siklus panjang maupun tugas yang bergantung pada dirinya sendiri (`"a": (f, ["a"])`) terdeteksi oleh Kahn dan menghasilkan `ValueError`.
* Dependensi ganda dalam satu daftar (misalnya `["a", "a"]`): diperlakukan sebagai satu dependensi, sehingga penghitung tidak macet.
* Kegagalan bercabang: tugas yang dependensinya gagal lewat beberapa jalur hanya dicatat sekali di `dilewati`. Tugas itu juga tidak akan dikirim meskipun dependensi lainnya selesai belakangan.
* Exception non-`Exception` (misalnya `KeyboardInterrupt` atau `SystemExit`): tidak ditelan dan diteruskan ke pemanggil, sesuai aturan yang hanya meminta penanganan `Exception`.
* Kamus tugas kosong: mengembalikan `({}, {}, set())`.
* Isolasi masukan: setiap fungsi menerima dict baru yang hanya berisi hasil dependensi langsungnya. Dict itu dibangun di thread utama, sehingga tidak ada balapan data pada `hasil`.
