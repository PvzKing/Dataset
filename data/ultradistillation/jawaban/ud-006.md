Pendekatan yang digunakan adalah memvalidasi dan membedah format teks setiap pertandingan menggunakan ekspresi reguler (regular expression). Statistik pertandingan—mencakup jumlah bermain, selisih gol, total gol yang dicetak (sebagai penentu peringkat ketiga), dan poin—diagregasi ke dalam struktur data kamus (dict). Setelah seluruh pertandingan diproses, data tim diurutkan berdasarkan hierarki penentu peringkat (poin menurun, selisih gol menurun, produktivitas gol menurun, lalu nama tim secara alfabetis menaik) dan dikonversi ke dalam format tuple yang diminta. 

```python
import re
from collections import defaultdict


def klasemen(hasil: list[str]) -> list[tuple[str, int, int, int]]:
    if not isinstance(hasil, list):
        raise ValueError("Parameter hasil harus berupa list")

    pola = re.compile(r"^(.+?)\s+([0-9]+)-([0-9]+)\s+(.+)$")
    # Struktur: [main, gol_masuk, gol_kemasukan, poin]
    stat = defaultdict(lambda: [0, 0, 0, 0])

    for baris in hasil:
        if not isinstance(baris, str):
            raise ValueError("Elemen pertandingan harus berupa string")

        cocok = pola.fullmatch(baris.strip())
        if not cocok:
            raise ValueError(f"Format pertandingan tidak valid: {baris!r}")

        tim1, s1, s2, tim2 = cocok.groups()
        tim1, tim2 = tim1.strip(), tim2.strip()

        # Validasi nama kosong dan tim yang bertanding melawan dirinya sendiri
        if not tim1 or not tim2 or tim1 == tim2:
            raise ValueError(f"Format pertandingan tidak valid: {baris!r}")

        gol1, gol2 = int(s1), int(s2)

        a, b = stat[tim1], stat[tim2]
        a[0] += 1
        b[0] += 1
        a[1] += gol1
        b[1] += gol2
        a[2] += gol2
        b[2] += gol1

        if gol1 > gol2:
            a[3] += 3
        elif gol1 < gol2:
            b[3] += 3
        else:
            a[3] += 1
            b[3] += 1

    # Urutkan langsung tanpa list perantara
    urut = sorted(
        stat.items(),
        key=lambda item: (
            -item[1][3],  # 1. Poin terbanyak
            -(item[1][1] - item[1][2]),  # 2. Selisih gol terbesar
            -item[1][1],  # 3. Gol memasukkan terbanyak
            item[0],  # 4. Abjad nama tim
        ),
    )

    return [(tim, d[0], d[1] - d[2], d[3]) for tim, d in urut]
```

Contoh pemakaian:

```python
>>> klasemen(["Persib 2-1 Persija", "Persija 3-3 PSM Makassar", "PSM Makassar 1-0 Persib"])
[('PSM Makassar', 2, 1, 4), ('Persib', 2, 0, 3), ('Persija', 2, -1, 1)]
>>> klasemen(["A 2-0 B", "C 3-1 D"])  # poin dan selisih gol sama, C unggul gol memasukkan
[('C', 1, 2, 3), ('A', 1, 2, 3), ('D', 1, -2, 0), ('B', 1, -2, 0)]
```

Kasus khusus yang ditangani:

- Daftar kosong menghasilkan `[]`.
- Nama tim boleh berspasi atau mengandung angka, misalnya `"Persis Solo 1923 2-1 PSIS"`, karena skor dikenali sebagai pola `angka-angka` yang diapit spasi.
- Spasi berlebih di awal, di akhir, atau di sekitar skor diabaikan.
- Urutan seri ditentukan berlapis: poin, selisih gol, gol memasukkan, lalu abjad nama tim.
- `ValueError` dilempar untuk string tanpa skor (`"Persib vs Persija"`), skor bukan angka (`"Persib 2-x Persija"`), nama tim kosong (`"2-1 Persija"`), skor negatif atau berspasi (`"A 2 - 1 B"`), tim yang melawan dirinya sendiri, elemen yang bukan string, dan argumen yang bukan list.
