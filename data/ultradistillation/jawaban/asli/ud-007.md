Pendekatannya: validasi input, ubah bunga tahunan menjadi bunga bulanan, hitung angsuran tetap dengan rumus anuitas (atau `pokok / tenor` bila bunga 0), lalu iterasi tiap bulan. Bunga dihitung dari sisa pinjaman; pada bulan terakhir pokok dibuat sama dengan seluruh sisa agar lunas tepat nol, dan angsuran bulan itu menyesuaikan pokok ditambah bunga.

```python
def jadwal_angsuran(pokok: int, bunga_tahunan: float, tenor: int) -> list[dict]:
    if pokok <= 0:
        raise ValueError("pokok harus lebih dari 0")
    if bunga_tahunan < 0:
        raise ValueError("bunga_tahunan tidak boleh negatif")
    if tenor <= 0:
        raise ValueError("tenor harus lebih dari 0")

    r = bunga_tahunan / 100.0 / 12.0

    if r == 0:
        angsuran_tetap = round(pokok / tenor)
    else:
        angsuran_tetap = round(pokok * r / (1 - (1 + r) ** (-tenor)))

    hasil = []
    sisa = pokok

    for bulan in range(1, tenor + 1):
        bunga = round(sisa * r)

        if bulan == tenor:
            pokok_bulan = sisa
            angsuran = pokok_bulan + bunga
            sisa_baru = 0
        else:
            pokok_bulan = angsuran_tetap - bunga
            angsuran = angsuran_tetap
            sisa_baru = sisa - pokok_bulan

        hasil.append({
            "bulan": bulan,
            "angsuran": angsuran,
            "bunga": bunga,
            "pokok": pokok_bulan,
            "sisa": sisa_baru,
        })

        sisa = sisa_baru

    return hasil
```

Contoh pemakaian: `jadwal_angsuran(12_000_000, 12, 12)` menghasilkan 12 baris jadwal bulanan, dengan baris terakhir memiliki `sisa` bernilai `0`. Kasus khusus yang ditangani: bunga 0 memakai pembagian pokok rata, tenor 1 langsung melunasi seluruh pokok pada bulan pertama, dan input pokok ≤ 0, bunga negatif, atau tenor ≤ 0 memunculkan `ValueError`.
