Pendekatannya: bersihkan dulu seluruh pemisah yang diizinkan (titik, tanda minus, dan spasi) di posisi mana pun, lalu kumpulkan hanya karakter digit 0–9. Jika muncul karakter lain, proses langsung gagal dengan `None`. Setelah itu, validasi jumlah digit: 15 digit diformat ke pola NPWP lama, 16 digit dikembalikan apa adanya tanpa pemisah, selain itu `None`.

```python
def normalisasi_npwp(teks: str) -> str | None:
    if not isinstance(teks, str):
        return None

    digit = []
    for ch in teks:
        if ch in ".- ":
            continue
        if "0" <= ch <= "9":
            digit.append(ch)
        else:
            return None

    angka = "".join(digit)

    if len(angka) == 15:
        return f"{angka[0:2]}.{angka[2:5]}.{angka[5:8]}.{angka[8]}-{angka[9:12]}.{angka[12:15]}"

    if len(angka) == 16:
        return angka

    return None
```

Contoh pemakaian: `normalisasi_npwp("99.999.999.9-999.999")` menghasilkan `"99.999.999.9-999.999"`; `normalisasi_npwp("1234567890123456")` menghasilkan `"1234567890123456"`; `normalisasi_npwp("12 345 678 901 234")` menghasilkan `"12345678901234"` jika totalnya 15 digit, atau bentuk 16 digit tanpa pemisah jika totalnya 16 digit. Kasus khusus yang ditangani: pemisah berulang/berada di posisi mana pun, masukan 15 digit, masukan 16 digit, karakter tidak valid seperti huruf atau simbol lain, dan jumlah digit selain 15/16.
