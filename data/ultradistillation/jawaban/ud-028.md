Pendekatannya: setiap stasiun dihitung jaraknya ke lokasi pengguna dengan rumus haversine (radius bumi 6.371 km), hasilnya dibulatkan ke 2 desimal, lalu daftar diurutkan berdasarkan jarak bulat terdekat dan nama stasiun jika jaraknya sama. Fungsi mengembalikan paling banyak `k` elemen, dan `ValueError` dilempar bila `k < 1`.

```python
import math

def stasiun_terdekat(
    lokasi: tuple[float, float],
    stasiun: dict[str, tuple[float, float]],
    k: int
) -> list[tuple[str, float]]:
    if k < 1:
        raise ValueError("k harus lebih besar dari atau sama dengan 1")

    lat1, lon1 = lokasi
    lat1_rad = math.radians(lat1)
    lon1_rad = math.radians(lon1)

    hasil = []
    for nama, (lat2, lon2) in stasiun.items():
        lat2_rad = math.radians(lat2)
        lon2_rad = math.radians(lon2)

        dlat = lat2_rad - lat1_rad
        dlon = lon2_rad - lon1_rad

        a = (
            math.sin(dlat / 2) ** 2
            + math.cos(lat1_rad) * math.cos(lat2_rad) * math.sin(dlon / 2) ** 2
        )
        a = min(1.0, max(0.0, a))
        c = 2 * math.asin(math.sqrt(a))
        jarak = 6371 * c

        hasil.append((nama, round(jarak, 2)))

    hasil.sort(key=lambda item: (item[1], item[0]))
    return hasil[:k]
```

Contoh pemakaian: `hasil = stasiun_terdekat((-6.2, 106.8), {"Manggarai": (-6.21, 106.85), "Tanah Abang": (-6.19, 106.81)}, 1)` menghasilkan `[("Tanah Abang", 1.57)]`; dengan `k=5` hasilnya `[("Tanah Abang", 1.57), ("Manggarai", 5.64)]`.

Kasus khusus yang ditangani: `k < 1` menghasilkan `ValueError`; `k` lebih besar dari jumlah stasiun mengembalikan semua stasiun; jarak sama setelah pembulatan diurutkan menurut nama; dan `stasiun` kosong dengan `k >= 1` mengembalikan list kosong.
