Pendekatannya memakai prefix doubling untuk suffix array dan algoritma Kasai untuk LCP. Karakter dipetakan dulu ke peringkat kecil (0, 1, 2, ...) sesuai urutan titik kode Unicode, jadi urutannya sama dengan perbandingan string Python. Pada setiap putaran, sufiks diurutkan menurut pasangan (peringkat 2^k karakter pertama, peringkat 2^k karakter berikutnya). Pasangan itu dikodekan menjadi satu bilangan bulat supaya pengurutan bawaan Python berjalan cepat. Sufiks yang habis lebih dulu mendapat nilai 0 pada bagian kedua, sehingga sufiks yang merupakan awalan sufiks lain berada di depan. Proses berhenti begitu semua peringkat berbeda, yaitu paling banyak sekitar log₂ n putaran, sehingga total kompleksitasnya O(n log² n). Kasai kemudian menghitung LCP dalam O(n) dengan memanfaatkan fakta bahwa nilai LCP turun paling banyak satu dari sufiks `i` ke sufiks `i+1`.

```python
def array_sufiks(s: str) -> tuple[list[int], list[int]]:
    n = len(s)
    if n == 0:
        return [], []

    # Peringkat awal: kompresi karakter sesuai urutan titik kode Unicode.
    alfabet = {c: i for i, c in enumerate(sorted(set(s)))}
    rank = [alfabet[c] for c in s]
    sa = list(range(n))
    sa.sort(key=rank.__getitem__)

    # Prefix doubling: ulangi sampai semua peringkat unik.
    if len(alfabet) < n:
        base = n + 1
        k = 1
        while True:
            # Bagian kedua: rank[i+k] + 1, atau 0 jika i+k di luar string.
            kedua = [r + 1 for r in rank[k:]]
            kedua.extend([0] * (n - len(kedua)))
            kunci = [a * base + b for a, b in zip(rank, kedua)]

            sa.sort(key=kunci.__getitem__)

            baru = [0] * n
            r = 0
            prev = kunci[sa[0]]
            for idx in sa[1:]:
                kv = kunci[idx]
                if kv != prev:
                    r += 1
                    prev = kv
                baru[idx] = r
            rank = baru

            if r == n - 1:
                break
            k <<= 1

    # Sekarang rank[i] adalah posisi sufiks i di dalam sa (invers sa).
    # LCP dengan algoritma Kasai.
    lcp = [0] * n
    h = 0
    for i in range(n):
        r = rank[i]
        if r == 0:
            h = 0
            continue
        j = sa[r - 1]
        while i + h < n and j + h < n and s[i + h] == s[j + h]:
            h += 1
        lcp[r] = h
        if h > 0:
            h -= 1

    return sa, lcp

```

Contoh pemakaian:

```python
array_sufiks("banana")
# ([5, 3, 1, 0, 4, 2], [0, 1, 3, 0, 0, 2])

array_sufiks("aaaa")
# ([3, 2, 1, 0], [0, 1, 2, 3])

array_sufiks("")
# ([], [])

```

Kasus khusus yang ditangani:

* String kosong langsung menghasilkan `([], [])`.
* String satu karakter menghasilkan `([0], [0])`.
* String yang semua karakternya berbeda sudah selesai setelah pengurutan awal, tanpa putaran doubling.
* Kasus terburuk seperti `'a' * 50000` hanya butuh sekitar 16 putaran pengurutan bilangan bulat. Kasai tetap linear karena `h` total naik paling banyak 2n kali, sehingga selesai jauh di bawah satu detik.
* Karakter Unicode di luar ASCII, termasuk emoji dan titik kode di atas U+FFFF, diurutkan per titik kode. Urutannya identik dengan `sorted(s[i:] for i in range(n))`.
* Sufiks yang merupakan awalan sufiks lain, misalnya `"a"` dan `"ana"`, diletakkan lebih dulu karena posisi di luar string diberi nilai 0, lebih kecil dari peringkat karakter mana pun.
