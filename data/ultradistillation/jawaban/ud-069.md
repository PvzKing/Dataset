Ekspresi diurai menjadi lima himpunan nilai yang sah. Setiap bagian yang dipisahkan koma diperiksa satu per satu: nama bulan dan nama hari diubah menjadi angka tanpa memedulikan huruf besar-kecil, rentang terbalik ditolak, langkah 0 ditolak, dan angka tunggal yang diberi langkah (`a/n`) dibaca sebagai `a` sampai nilai maksimum kolom. Nilai hari 7 disamakan dengan 0. Program juga mencatat apakah kolom tanggal dan kolom hari diawali `*`, untuk menentukan apakah keduanya harus cocok atau cukup salah satunya.
Pencarian berjalan per hari, tidak per menit. Bulan yang tidak ada dalam himpunan dilompati langsung ke tanggal 1 bulan berikutnya. Pada hari yang cocok, program mengambil jam dan menit terkecil yang masih memenuhi batas awal. Dengan cara ini, jangka 50 tahun hanya membutuhkan paling banyak sekitar 18.000 langkah harian. Jika batas itu terlewati tanpa ada yang cocok, fungsi melempar `ValueError`.

```python
import datetime
import re

_ANGKA = re.compile(r"[0-9]+")
_NAMA_BULAN = {n: i for i, n in enumerate(
    ["JAN", "FEB", "MAR", "APR", "MAY", "JUN",
     "JUL", "AUG", "SEP", "OCT", "NOV", "DEC"], start=1)}
_NAMA_HARI = {n: i for i, n in enumerate(
    ["SUN", "MON", "TUE", "WED", "THU", "FRI", "SAT"])}


def _nilai(tok, lo, hi, nama):
    if _ANGKA.fullmatch(tok):
        v = int(tok)
    elif nama and tok.upper() in nama:
        v = nama[tok.upper()]
    else:
        raise ValueError(f"nilai tidak sah: {tok!r}")
    if not lo <= v <= hi:
        raise ValueError(f"nilai di luar rentang {lo}-{hi}: {tok!r}")
    return v


def _kolom(teks, lo, hi, nama=None):
    hasil = set()
    for bagian in teks.split(","):
        if not bagian:
            raise ValueError(f"bagian kosong dalam {teks!r}")
        if "/" in bagian:
            dasar, langkah = bagian.split("/", 1)
            if not _ANGKA.fullmatch(langkah) or int(langkah) == 0:
                raise ValueError(f"langkah tidak sah: {bagian!r}")
            langkah = int(langkah)
            ada_langkah = True
        else:
            dasar, langkah, ada_langkah = bagian, 1, False

        if dasar == "*":
            a, b = lo, hi
        elif "-" in dasar:
            x, y = dasar.split("-", 1)
            a, b = _nilai(x, lo, hi, nama), _nilai(y, lo, hi, nama)
            if a > b:
                raise ValueError(f"rentang terbalik: {dasar!r}")
        else:
            a = _nilai(dasar, lo, hi, nama)
            b = hi if ada_langkah else a  # gaya Vixie: 5/20 -> 5,25,45
        hasil.update(range(a, b + 1, langkah))
    return hasil


def cron_berikutnya(ekspresi: str, setelah: datetime.datetime) -> datetime.datetime:
    kolom = ekspresi.split()
    if len(kolom) != 5:
        raise ValueError("ekspresi cron harus terdiri dari lima kolom")
    t_menit, t_jam, t_tgl, t_bln, t_hari = kolom

    menit = sorted(_kolom(t_menit, 0, 59))
    jam = sorted(_kolom(t_jam, 0, 23))
    tanggal = _kolom(t_tgl, 1, 31)
    bulan = _kolom(t_bln, 1, 12, _NAMA_BULAN)
    hari = {0 if v == 7 else v for v in _kolom(t_hari, 0, 7, _NAMA_HARI)}

    bintang = t_tgl.startswith("*") or t_hari.startswith("*")

    def hari_cocok(d):
        ok_tgl = d.day in tanggal
        ok_hari = (d.weekday() + 1) % 7 in hari  # Senin=0 -> cron Minggu=0
        return (ok_tgl and ok_hari) if bintang else (ok_tgl or ok_hari)

    try:
        mulai = setelah.replace(second=0, microsecond=0) + datetime.timedelta(minutes=1)
        d = mulai.date()
        try:
            batas = d.replace(year=d.year + 50)
        except ValueError:  # 29 Februari
            batas = d.replace(year=d.year + 50, day=28)

        while d <= batas:
            if d.month not in bulan:
                d = datetime.date(d.year + d.month // 12, d.month % 12 + 1, 1)
                continue
            if hari_cocok(d):
                jh, jm = (mulai.hour, mulai.minute) if d == mulai.date() else (0, 0)
                for h in jam:
                    if h < jh:
                        continue
                    for m in menit:
                        if h == jh and m < jm:
                            continue
                        return datetime.datetime.combine(
                            d, datetime.time(h, m), tzinfo=mulai.tzinfo)
            d += datetime.timedelta(days=1)
    except OverflowError:
        pass
    raise ValueError("tidak ada waktu yang cocok dalam 50 tahun ke depan")

```

Contoh pemakaian (24 Oktober 2026 jatuh pada hari Sabtu):

```python
from datetime import datetime

cron_berikutnya("*/15 9-17 * * MON-FRI", datetime(2026, 10, 24, 6, 33))
# -> 2026-10-26 09:00 (Senin)

cron_berikutnya("30 8 1,15 * 5", datetime(2026, 10, 24, 6, 33))
# -> 2026-10-30 08:30 (cukup salah satu cocok: hari Jumat)

cron_berikutnya("0 12 */2 * 1", datetime(2026, 10, 24, 6, 33))
# -> 2026-11-09 12:00 (harus tanggal ganjil DAN hari Senin)

cron_berikutnya("5/20 * * * *", datetime(2026, 10, 24, 6, 33, 59))
# -> 2026-10-24 06:45

cron_berikutnya("0 0 31 4 *", datetime(2026, 10, 24))
# -> ValueError

```

Kasus khusus yang ditangani:

* Waktu awal yang sudah cocok tidak dihitung. Detik dan mikrodetik dibuang, lalu pencarian dimulai satu menit setelahnya. Jadi hasilnya selalu lebih dari `setelah`.
* Hari 0 dan 7 sama-sama Minggu. Rentang seperti `5-7` (Jumat sampai Minggu) juga berlaku.
* Nama tidak peka huruf besar-kecil, misalnya `jan`, `Mon-fri`, atau `DEC`. Nama juga boleh dipakai di dalam rentang dan sebelum langkah.
* Aturan tanggal dan hari mengikuti Vixie cron. Kolom yang diawali `*`, termasuk `*/2`, membuat kedua kolom wajib cocok. Selain itu, cukup salah satu yang cocok.
* Tanggal 29 Februari ditemukan pada tahun kabisat berikutnya. Tanggal yang mustahil, seperti 30 Februari atau 31 April, menghasilkan `ValueError`.
* Ekspresi tidak sah menghasilkan `ValueError`. Ini mencakup jumlah kolom yang salah, nilai di luar rentang, rentang terbalik, `*/0`, nama tak dikenal, bagian kosong (`1,,2`, `/5`, `3-`), dan angka bertanda seperti `-1`.
* Zona waktu. `tzinfo` pada `setelah` dipertahankan. Perhitungannya memakai jam dinding, sehingga untuk zona dengan DST, celah atau pengulangan jam tidak diperlakukan secara khusus.
