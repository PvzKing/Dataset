Pendekatannya: bersihkan dulu tanda hubung dan spasi, lalu periksa apakah panjangnya 10 atau 13. Untuk ISBN-10, pastikan 9 karakter pertama berupa angka ASCII dan karakter terakhir angka atau `X/x`, kemudian hitung bobot 10 sampai 1 modulo 11. Untuk ISBN-13, pastikan semua karakter angka, awalan `978`/`979`, lalu hitung bobot bergantian 1 dan 3 modulo 10.

```python
def validasi_isbn(teks: str) -> bool:
    if not isinstance(teks, str):
        return False

    bersih = teks.replace("-", "").replace(" ", "")

    if len(bersih) == 10:
        if any(c not in "0123456789" for c in bersih[:9]):
            return False

        cek = bersih[9]
        if cek in "Xx":
            nilai_cek = 10
        elif cek in "0123456789":
            nilai_cek = int(cek)
        else:
            return False

        nilai = [int(c) for c in bersih[:9]] + [nilai_cek]
        total = sum(n * bobot for n, bobot in zip(nilai, range(10, 0, -1)))
        return total % 11 == 0

    if len(bersih) == 13:
        if any(c not in "0123456789" for c in bersih):
            return False
        if not (bersih.startswith("978") or bersih.startswith("979")):
            return False

        total = sum(
            int(c) * (1 if i % 2 == 0 else 3)
            for i, c in enumerate(bersih)
        )
        return total % 10 == 0

    return False
```

Contoh pemakaian: `validasi_isbn("0-306-40615-2")` menghasilkan `True`; `validasi_isbn("978-0-306-40615-7")` menghasilkan `True`; `validasi_isbn("0-8044-2957-X")` menghasilkan `True`. Kasus khusus yang ditangani: spasi dan tanda hubung diabaikan, `X/x` hanya diterima sebagai karakter cek ISBN-10, ISBN-13 wajib diawali `978`/`979`, serta karakter lain, panjang salah, atau format tidak sesuai menghasilkan `False`.
