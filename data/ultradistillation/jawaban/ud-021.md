Pendekatannya adalah memecah bilangan menjadi kelompok tiga digit dari kanan, mengonversi tiap kelompok dengan aturan khusus untuk 10, 11, 100, dan 1000, lalu menggabungkannya dengan satuan ribu, juta, miliar, dan triliun. Nilai nol, bilangan negatif, dan batas nilai absolut 10^15 ditangani secara terpisah.

```python
def terbilang(n: int) -> str:
    if abs(n) >= 10**15:
        raise ValueError("nilai absolut harus kurang dari 10^15")

    satuan = [
        "", "satu", "dua", "tiga", "empat",
        "lima", "enam", "tujuh", "delapan", "sembilan"
    ]

    def tiga_digit(x: int) -> str:
        if x == 0:
            return ""
        if x < 10:
            return satuan[x]
        if x == 10:
            return "sepuluh"
        if x == 11:
            return "sebelas"
        if x < 20:
            return satuan[x - 10] + " belas"
        if x < 100:
            hasil = satuan[x // 10] + " puluh"
            if x % 10:
                hasil += " " + satuan[x % 10]
            return hasil
        if x == 100:
            return "seratus"
        if x < 200:
            hasil = "seratus"
            if x > 100:
                hasil += " " + tiga_digit(x - 100)
            return hasil

        hasil = satuan[x // 100] + " ratus"
        if x % 100:
            hasil += " " + tiga_digit(x % 100)
        return hasil

    if n == 0:
        return "nol"

    negatif = n < 0
    n = abs(n)

    unit = ["", "ribu", "juta", "miliar", "triliun"]
    bagian = []
    i = 0

    while n > 0:
        grup = n % 1000
        if grup:
            if i == 1 and grup == 1:
                kata = "seribu"
            else:
                kata = tiga_digit(grup)
                if i > 0:
                    kata += " " + unit[i]
            bagian.append(kata)

        n //= 1000
        i += 1

    hasil = " ".join(reversed(bagian))
    if negatif:
        hasil = "minus " + hasil

    return hasil
```

Contoh pemakaian: `terbilang(2_150_000)` menghasilkan `"dua juta seratus lima puluh ribu"`; `terbilang(0)` menghasilkan `"nol"`; `terbilang(-11)` menghasilkan `"minus sebelas"`; `terbilang(101_000)` menghasilkan `"seratus satu ribu"`; `terbilang(10**15)` melempar `ValueError`. Kasus khusus yang ditangani mencakup nol, bilangan negatif, 10, 11, 100, 1000, kelompok ribuan seperti 101.000, serta batas nilai absolut 10^15.
