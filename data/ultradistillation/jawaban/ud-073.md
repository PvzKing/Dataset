Pendekatannya memakai graf implikasi. Setiap klausa `a OR b` setara dengan dua implikasi, yaitu `¬a → b` dan `¬b → a`. Setiap literal menjadi simpul: variabel ke-k memakai simpul `2(k−1)` untuk "benar" dan `2(k−1)+1` untuk "salah", sehingga negasi cukup dihitung dengan `simpul ^ 1`.
Formula tidak terpenuhi tepat ketika suatu literal dan negasinya berada dalam komponen terhubung kuat (SCC) yang sama. Kalau tidak ada yang begitu, algoritma Tarjan menomori SCC dalam urutan topologis terbalik. Karena itu, sebuah literal diberi nilai benar jika nomor komponennya lebih kecil daripada nomor komponen negasinya.
Agar aman untuk rantai implikasi yang sangat panjang, Tarjan ditulis secara iteratif dengan tumpukan eksplisit, jadi batas rekursi Python tidak tersentuh. Graf disimpan dalam format CSR (array `awal` dan `tujuan`) supaya hemat memori dan cepat. Seluruh algoritma berjalan dalam waktu O(n + m).

```python
def dua_sat(n: int, klausa: list[tuple[int, int]]) -> list[bool] | None:
    """Menyelesaikan 2-SAT dengan graf implikasi dan Tarjan SCC iteratif.

    Mengembalikan list n nilai bool untuk variabel 1..n, atau None jika
    formula tidak dapat dipenuhi. Melempar ValueError untuk literal tidak sah.
    """
    if not isinstance(n, int) or isinstance(n, bool) or n < 0:
        raise ValueError("n harus bilangan bulat non-negatif")

    N = 2 * n

    def simpul(lit) -> int:
        if not isinstance(lit, int) or isinstance(lit, bool):
            raise ValueError(f"literal harus bilangan bulat: {lit!r}")
        if lit == 0 or abs(lit) > n:
            raise ValueError(f"literal tidak sah: {lit}")
        return 2 * (lit - 1) if lit > 0 else 2 * (-lit - 1) + 1

    # Validasi dan konversi literal ke nomor simpul
    sumber = []
    target = []
    for k in klausa:
        try:
            a, b = k
        except (TypeError, ValueError):
            raise ValueError(f"klausa harus berupa pasangan dua literal: {k!r}")
        u = simpul(a)
        v = simpul(b)
        # a OR b  ==>  (¬a -> b) dan (¬b -> a)
        sumber.append(u ^ 1); target.append(v)
        sumber.append(v ^ 1); target.append(u)

    if n == 0:
        return []

    # Bangun adjacency dalam format CSR
    derajat = [0] * (N + 1)
    for s in sumber:
        derajat[s + 1] += 1
    for i in range(N):
        derajat[i + 1] += derajat[i]
    awal = derajat                      # awal[v] .. awal[v+1]-1 adalah tetangga v
    isi = awal[:N]                      # penunjuk pengisian sementara
    tujuan = [0] * len(sumber)
    for s, t in zip(sumber, target):
        tujuan[isi[s]] = t
        isi[s] += 1
    del sumber, target, isi

    # Tarjan SCC iteratif
    indeks = [-1] * N
    low = [0] * N
    di_tumpukan = [False] * N
    komp = [-1] * N
    ptr = [0] * N
    tumpukan = []
    nomor = 0
    jumlah_komp = 0

    for s in range(N):
        if indeks[s] != -1:
            continue
        indeks[s] = low[s] = nomor
        nomor += 1
        tumpukan.append(s)
        di_tumpukan[s] = True
        ptr[s] = awal[s]
        panggilan = [s]

        while panggilan:
            v = panggilan[-1]
            i = ptr[v]
            akhir = awal[v + 1]
            turun = False
            while i < akhir:
                w = tujuan[i]
                i += 1
                if indeks[w] == -1:
                    ptr[v] = i
                    indeks[w] = low[w] = nomor
                    nomor += 1
                    tumpukan.append(w)
                    di_tumpukan[w] = True
                    ptr[w] = awal[w]
                    panggilan.append(w)
                    turun = True
                    break
                elif di_tumpukan[w] and indeks[w] < low[v]:
                    low[v] = indeks[w]
            if turun:
                continue

            ptr[v] = i
            panggilan.pop()
            if low[v] == indeks[v]:
                while True:
                    w = tumpukan.pop()
                    di_tumpukan[w] = False
                    komp[w] = jumlah_komp
                    if w == v:
                        break
                jumlah_komp += 1
            if panggilan:
                u = panggilan[-1]
                if low[v] < low[u]:
                    low[u] = low[v]

    # Periksa konsistensi dan susun penugasan
    hasil = [False] * n
    for x in range(n):
        cb = komp[2 * x]
        cs = komp[2 * x + 1]
        if cb == cs:
            return None
        # Tarjan menomori SCC dalam urutan topologis terbalik
        hasil[x] = cb < cs
    return hasil

```

Contoh pemakaian:

```python
dua_sat(2, [(1, 2), (-1, 2), (-2, 1)])   # [True, True]
dua_sat(1, [(1, 1), (-1, -1)])           # None (x1 harus benar sekaligus salah)
dua_sat(0, [])                           # []
dua_sat(3, [(1, 4)])                     # ValueError (4 > n)
dua_sat(3, [(0, 1)])                     # ValueError (literal 0)

# Rantai panjang: x1 -> x2 -> ... -> x50000, dengan x1 dipaksa benar
n = 50_000
kl = [(1, 1)] + [(-i, i + 1) for i in range(1, n)]
assert all(dua_sat(n, kl))               # selesai cepat, tanpa RecursionError

```

Kasus khusus yang ditangani:

* Klausa `(a, a)` memaksa literal `a` bernilai benar. Klausa ini menghasilkan sisi `¬a → a`, dua kali, dan itu tidak masalah.
* Klausa `(a, -a)` selalu benar. Klausa ini hanya menambah sisi `¬a → ¬a` dan `a → a`, yang tidak memengaruhi hasil.
* `n = 0` tanpa klausa menghasilkan `[]`. Jika `n = 0` tetapi ada klausa, setiap literal pasti melebihi `n`, sehingga fungsi melempar `ValueError`.
* Literal tidak sah memicu `ValueError`, yaitu literal `0`, literal dengan `|k| > n`, literal yang bukan bilangan bulat (termasuk `bool`), dan klausa yang bukan pasangan dua elemen. Validasi dilakukan sebelum graf dibangun.
* Variabel yang tidak muncul di klausa mana pun tetap mendapat nilai (`False`) dalam list hasil.
* Rantai implikasi puluhan ribu langkah aman karena DFS memakai tumpukan eksplisit, bukan rekursi. Untuk n = 50.000 dan sekitar 150.000 klausa (300.000 sisi), waktu jalannya umumnya di bawah satu detik.
