Pendekatannya memakai substitusi Kronecker: kedua polinom "dievaluasi" di titik x = 2ᵏ sehingga masing-masing menjadi satu bilangan bulat besar. Kedua bilangan itu dikalikan dengan perkalian `int` bawaan Python, yang memakai Karatsuba dan tetap eksak berapa pun ukurannya. Hasilnya lalu dipecah kembali per blok k bit menjadi koefisien.
Agar blok-blok tidak saling "meluap", k dipilih supaya 2ᵏ⁻¹ melebihi batas atas nilai mutlak koefisien hasil, yaitu `min(len a, len b) · max|aᵢ| · max|bⱼ|`. Untuk koefisien sampai 10⁹ dan 20.000 suku, batas ini sekitar 2·10²², jadi cukup 80 bit (10 byte) per blok.
Koefisien negatif ditangani dengan dua cara. Saat pengodean, bagian positif dan negatif dikemas terpisah lalu dikurangkan. Saat pembacaan, setiap blok ditambah offset 2ᵏ⁻¹ sehingga semua blok menjadi tak-negatif dan bisa dibaca langsung dari representasi byte. Lebar blok dibulatkan ke kelipatan 8 bit, sehingga konversi bolak-balik cukup memakai `int.from_bytes`/`to_bytes` yang berjalan linear.
Kompleksitas totalnya didominasi satu perkalian bilangan besar berukuran sekitar 1,6 juta bit, yang selesai jauh di bawah satu detik.

```python
def kali_polinom(a: list[int], b: list[int]) -> list[int]:
    """Mengalikan dua polinom berkoefisien bulat secara eksak.

    Elemen ke-i adalah koefisien x^i. Hasil berpanjang len(a)+len(b)-1
    (nol di akhir tidak dibuang); jika salah satu list kosong, hasilnya [].
    Memakai substitusi Kronecker: polinom dikemas menjadi bilangan bulat
    besar, dikalikan dengan perkalian int bawaan, lalu dibongkar kembali.
    """
    la, lb = len(a), len(b)
    if la == 0 or lb == 0:
        return []

    for x in a:
        if not isinstance(x, int) or isinstance(x, bool):
            raise TypeError(f"koefisien harus bilangan bulat: {x!r}")
    for x in b:
        if not isinstance(x, int) or isinstance(x, bool):
            raise TypeError(f"koefisien harus bilangan bulat: {x!r}")

    L = la + lb - 1
    maks_a = max(abs(x) for x in a)
    maks_b = max(abs(x) for x in b)
    if maks_a == 0 or maks_b == 0:
        return [0] * L

    # Batas atas |c_i|; butuh 2^(k-1) > batas agar tiap blok tidak meluap
    batas = min(la, lb) * maks_a * maks_b
    k = batas.bit_length() + 1
    K = (k + 7) // 8            # lebar blok dalam byte
    k = 8 * K
    nol = bytes(K)

    def kemas(koef: list[int]) -> int:
        """Menghitung sum koef[i] * 2^(k*i) dalam waktu linear."""
        pos = b"".join(x.to_bytes(K, "little") if x > 0 else nol for x in koef)
        neg = b"".join((-x).to_bytes(K, "little") if x < 0 else nol for x in koef)
        return int.from_bytes(pos, "little") - int.from_bytes(neg, "little")

    C = kemas(a) * kemas(b)

    # Tambah 2^(k-1) ke setiap blok agar semua digit basis 2^k tak-negatif
    setengah = 1 << (k - 1)
    offset = int.from_bytes(setengah.to_bytes(K, "little") * L, "little")
    data = (C + offset).to_bytes(L * K, "little")

    dari_bytes = int.from_bytes
    return [
        dari_bytes(data[i:i + K], "little") - setengah
        for i in range(0, L * K, K)
    ]

```

Contoh pemakaian:

```python
kali_polinom([1, 2], [3, -1])        # [3, 5, -2]   -> (1+2x)(3-x) = 3 + 5x - 2x²
kali_polinom([0, 0], [1])            # [0, 0]       (nol di akhir dipertahankan)
kali_polinom([], [1, 2, 3])          # []
kali_polinom([10**9], [-10**9])      # [-1000000000000000000]

# Uji ukuran besar dan bandingkan dengan perkalian naif pada potongan kecil
import random
a = [random.randint(-10**9, 10**9) for _ in range(20_000)]
b = [random.randint(-10**9, 10**9) for _ in range(20_000)]
c = kali_polinom(a, b)               # selesai dalam hitungan detik
assert len(c) == 39_999
assert c[0] == a[0] * b[0] and c[-1] == a[-1] * b[-1]

```

Kasus khusus yang ditangani:

* List kosong di salah satu argumen menghasilkan `[]`.
* Semua koefisien nol di salah satu polinom langsung menghasilkan list nol sepanjang `len(a) + len(b) - 1`, tanpa perlu mengalikan.
* Nol di akhir (misalnya `[1, 0, 0]`) tidak dibuang, jadi panjang hasil selalu tepat `len(a) + len(b) - 1`.
* Koefisien negatif di input maupun hasil ditangani dengan pemisahan bagian positif dan negatif saat pengodean, serta offset 2ᵏ⁻¹ saat pembacaan.
* Ketepatan terjamin karena seluruh perhitungan memakai bilangan bulat Python tanpa floating point. Lebar blok dihitung dari data, sehingga fungsi tetap benar walaupun koefisien melampaui 10⁹; batas 10⁹ hanya memengaruhi kecepatan.
* Polinom dengan panjang sangat timpang (misalnya 1 suku dikali 20.000 suku) juga efisien, karena lebar blok ditentukan oleh `min(len a, len b)`.
* Koefisien yang bukan bilangan bulat, termasuk `bool` dan `float`, memicu `TypeError` agar hasil tidak diam-diam salah.
