# Catatan untuk Claude

Repo ini berisi dataset instruct berbahasa Indonesia dan perangkat fine-tuning. Lihat README untuk detailnya.

- **Berjalan di Google Colab:** notebook menyalin `docs/RUNBOOK_CLAUDE.md` ke `/content/CLAUDE.md`. Ikuti runbook itu saat diminta melatih atau memantau training.
- **Mengubah `scripts/train_unsloth.py` atau `docs/RUNBOOK_CLAUDE.md`:** jalankan `python scripts/build_notebook.py` supaya notebook ikut diperbarui.
- **Mengubah `data/train.jsonl`:** jalankan `python scripts/validate.py`.
- **Isi tag `<think>`:** ditulis sendiri oleh pemilik repo lewat `scripts/editor_think.py` dan disimpan di `data/think/<id>-<n>.md`. Jangan menulis, mengusulkan, atau mengubah isinya kecuali diminta secara eksplisit. Pasang ulang ke `train.jsonl` dengan `python scripts/think_tags.py apply`.
- **Mengubah sampel Python:** edit sumbernya di `data/python-src/<id>/`, bukan `train.jsonl`, lalu jalankan `python scripts/build_python_samples.py` dan `python scripts/decontaminate.py`.
- **Mengubah `eval-suite/`:** jalankan `python eval-suite/indopy/cek_soal.py` dan `python eval-suite/web/uji_pemeriksa.py`. Isi `eval-suite/` adalah data uji: jangan dijadikan sampel latihan.
- **Mengubah website di `examples/web/`:** jalankan juga tes browser di `tests/`.
- **Mengubah `examples/web-pilihan/`:** jalankan `WEB_DIR=web-pilihan node test_web.mjs` dari `tests/`. Folder ini etalase, bukan data latihan. Versi datanya ada di `examples/web/27-`…`41-` (sampel `web-027`–`web-041`); perubahan di etalase tidak otomatis ikut ke sana.
- **Mengubah `examples/web/27-`…`41-`:** salin HTML yang sama ke sampelnya di `data/train.jsonl`, lalu jalankan `python scripts/validate.py` dan tes browser. Jaga panjang sampel tetap ±6.200 token atau kurang. Jangan menambah sampel yang tugasnya sama dengan soal Web-eval.
- **Mengubah `docs/PROSEDUR_V4.md`:** jalankan `python scripts/md_to_notebook.py` supaya `notebooks/v4_pilot_colab.ipynb` ikut diperbarui.
- **Mengubah `docs/PANDUAN_V5_A100.md`:** jalankan `python scripts/md_to_notebook.py docs/PANDUAN_V5_A100.md notebooks/v5_a100_colab.ipynb`. Lalu uji alur sel-selnya tanpa GPU dengan `python tests/simulasi_v5/cek.py` (menulis ke `/content`, jadi hanya di container sekali pakai).
- **Mengubah `docs/PANDUAN_V6_A100.md`:** jalankan `python scripts/md_to_notebook.py docs/PANDUAN_V6_A100.md notebooks/v6_a100_colab.ipynb`, lalu `python tests/simulasi_v6/cek.py` (menulis ke `/content`, jadi hanya di container sekali pakai).
- **Mengubah `docs/PANDUAN_V7_A100.md`:** jalankan `python scripts/md_to_notebook.py docs/PANDUAN_V7_A100.md notebooks/v7_a100_colab.ipynb`, lalu `python tests/simulasi_v7/cek.py` (menulis ke `/content`, jadi hanya di container sekali pakai).
- **Mengubah `scripts/sulingan.py` atau `data/sulingan/`:** jalankan `python tests/simulasi_v7/cek.py` (dengan `CHROMIUM=/opt/pw-browsers/chromium` jika Chromium Playwright tidak di lokasi bawaan). Prompt di `data/sulingan/prompt-web.jsonl` tidak boleh sama tugasnya dengan soal Web-eval, prompt uji `train_unsloth.py` (bengkel, absensi), atau prompt uji antrean puskesmas.
- **Ultradistillation (`data/ultradistillation/`):** jawaban AI lain yang dikirim pemilik repo. Simpan apa adanya dengan `python scripts/ultradistillation.py simpan <id> --sumber "<AI dan versinya>"`, jangan disunting, dan jangan mengisi jawaban sendiri. Jawaban hukum hanya ditandai `periksa` jika pemilik menyatakan sudah memeriksanya. Setelah menambah jawaban atau pertanyaan, jalankan `python scripts/ultradistillation.py bangun` dan `python scripts/ultradistillation.py salin`. Pertanyaan baru tidak boleh sama tugasnya dengan soal uji, prompt uji, atau prompt sulingan V7.
- **Mengubah `data/bench-support/`:** bangun ulang dengan `python scripts/build_bench_support.py`, jangan diedit tangan. Pastikan uji yang bersih tetap bersih: `python scripts/decontaminate.py --sumber IndoPy Web-eval --data data/bench-support/*.jsonl`.
- **Mengubah `docs/PROSEDUR_V4_A100.md`:** jalankan `python scripts/md_to_notebook.py docs/PROSEDUR_V4_A100.md notebooks/v4_a100_colab.ipynb`.
- **Mengubah `scripts/panel_v4.py` atau `scripts/build_panel_notebook.py`:** jalankan `python scripts/build_panel_notebook.py` dan uji alurnya dengan `python scripts/panel_v4.py --demo /tmp/panel-demo` dan `python scripts/panel_v4.py --demo /tmp/panel-demo-a100 --a100`. Pilihan langkah di kedua notebook harus sama dengan judul langkah di panel.
